# 移动、空军任务与 ZOC 重构

本轮依据仓库配套 OCS 4.3 规则与 Smolensk 专规，继续拆分运行状态，修正实际操作入口，而非重写整个项目。规则版本不升级；现有 v6 存档字段保持兼容。

## 地面移动与空军任务

- 地面单位逐格移动，计算移动力、地形、燃料、堆叠及 ZOC。当前单位或堆叠走过一步后，须先结束移动，才能开始另一组（6.1g）。
- 空军按任务和航程处理，不累计地面移动力，也不需要声明逐格飞行路径；飞行不受地面地形、敌军地面单位及 ZOC 阻挡（14.2c/d）。空运和空投的地面货物仍须执行各自限制。
- 空军任务保留 A–G 流程。未完成任务不能通过换类型、换目标、取消面板或换阶段擦除；退出编队使用规则允许的主动返航。F 步必须实际完成炮击、阻断或货物结算，不能仅填备注跳过。
- 返航成功后同步飞机所在基地、激活状态及出动次数。反应段任务由非阶段玩家执行，不能沿用阶段玩家身份。

## ZOC 必须按操作区分

`zoc-effects.ts` 集中声明抵消政策；`inEnemyZocForAction` 为调用者提供统一判据。ZOC 投射来源与抵消后的具体效果分开计算。

| 操作                         | 友军占格抵消是否有效 | 依据与效果                                                      |
| ---------------------------- | -------------------- | --------------------------------------------------------------- |
| 普通轮式移动                 | 有效，须遵守抵消承诺 | 4.5a-A：进入有效敌 ZOC 须停止或突袭；履带、徒步不受这条停车限制 |
| 轮式抽取、投送和延伸补给路径 | 有效，须遵守抵消承诺 | 4.5a-B；徒步、履带路径按各自规则                                |
| 实际铁路运输                 | 无效                 | 4.5a-C                                                          |
| 铁路补给追溯                 | 有效                 | 4.5a-D                                                          |
| 轨距转换                     | 无效                 | 4.5a-E、13.3f-A                                                 |
| 空军整备                     | 有效                 | 4.5a-H                                                          |
| 转入预备模式                 | 无效                 | 4.5a-I；已在预备模式中的移动另判                                |
| 转入战略模式、战略移动       | 无效                 | 4.5a-J、5.8                                                     |
| 重建                         | 无效                 | 4.5a-K                                                          |
| 战斗撤退                     | 无效                 | 9.12e                                                           |

ZOC 不等于禁止一切战斗或推进。突袭、撤退、战后推进分别使用自身规则；不能把普通移动的有效 ZOC 检查机械复用于所有动作。本轮修正了模式切换、战略移动、铁路运输、轨距转换和重建入口的混用。

## 状态与撤销

- `ground-movement.ts` 接管移动交互、迈步、撤销和整段取消；`movement-types.ts` 保持原有对外类型兼容。
- `air-mission.ts` 接管空军运行状态、任务完成与返航提交；工作台继续负责界面输入与各域接线。
- 普通移动仍可撤销。触发特殊战斗、缴获、施工标记摧毁、突袭付款或开始空军任务后建立不可回滚边界，避免只撤回位置，却保留收益、骰子或已发生的战果。
- 战斗、轰炸、特殊战斗和空军任务未完成时，阻止继续移动或撤销。货物结算增加重复提交保护，避免重复投放或重掷。

## 验证与后续范围

新增规则政策和真实运行时回归用例，检查战略模式不能借友军抵消进入 ZOC、普通移动撤销、缴获后的撤销保护、任务中途改选、返航位置、反应玩家身份和重复提交。旧流程测试补齐任务结算与返航；轨距转换测试改为规则明确要求的不可抵消。

全量回归通过：305 个测试文件、4026 项用例；类型检查、代码检查、架构扫描与生产构建通过。补充移动收束闸门后另跑相关回归，并增加任务期间禁止结束或拆分地面移动的用例。

仍需独立完成的专项：空运 SP 货物的起点实物扣账与守恒；移动环节中为补给路径抵消 ZOC 时，对占格单位明确登记 4.5b 的本环节不可再花移动力承诺。当前部分补给判断依然按友军战斗单位占格自动抵消，不能据此宣称这两个环节已经全面验收。
