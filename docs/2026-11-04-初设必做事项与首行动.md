# S1第四批：初设必做事项与首行动

代码基线为`0f4c771`。本批继续初设的决策与交接链，并将开局验证延伸到真实移动及保存恢复；未修改逐回合增援、苏军动员或空运。

## 已复现及修复

| 入口                                      | 原行为                                                          | 本批结果                                                                                   |
| ----------------------------------------- | --------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| 剧本3/4/5/6，未选择规定满载卡车即结束初设 | 开局门禁仅查编队抽签，满载选择可被跳过                          | 当前满载名单及实际载货均符合剧本才放行；轴方不能在本方必做事项未完时确认                   |
| 已确认满载，再更换同额名单                | 旧完成标记仍为真，所选车辆与实际载货可能不同                    | 修改名单使完成标记失效，完成度重新核对实物；重新落账后才可收束                             |
| 已选够满载名额，其余车辆按规则空载        | 仍把所有未满载车辆计作“待定”，使队列看起来永远未完成            | 选额与载货完成后，其余车辆为空载完成项；方别待办只统计剩余事项                             |
| 正式新局直接调开始入口，未逐方确认        | store可以绕过界面的双方确认顺序                                 | 游标尚未完成交接时拒绝收束与开始；普通未摆单位的主动放弃口径保留                           |
| 一方正在点地图落位或点卡车，此时确认换手  | 前一方的点选状态残留，可影响后一方操作                          | 成功换手清除落位和点车操作；确认被拒时保留修正入口                                         |
| 未完成西移等必做事项，打开“放弃未布设项”  | 必做事项与普通新单位混在一张放弃清单里，按钮点下后才被store拒绝 | 必做清单单列；放弃清单只含普通未摆地面/非战斗/飞机项，必做未完时按钮禁用；清单变化重置勾选 |
| 多个抽中西移编队待摆                      | 卡片使用同一个`entryIndex=-1`作为键的一部分，缺少编队标识       | 卡片键加入编队ID，逐卡保持身份                                                             |
| 徒步单位走一格并点“结束移动”后保存        | 已结束但仍供显示的移动记录被当成未完结算，存档拒绝              | 仅未结束的移动阻止保存，已结束移动保存盘面事实，恢复后MP与位置一致                         |

卡车名额继续使用既有`scenarios.json.setup.organicTrucks`与`planTruckFullLoad`，没有新增或更改规则数值。依据为[官方规则](https://mmpgamers.com/support/gamersarchive/ocs/SmolenskRules.pdf)的Setup Note C、剧本3/5专规及13.2h载货记法；普通未摆新单位可主动放弃，继续采用用户已确认的口径。

## 分工与回归

`engine/rules/setup-obligations.ts`复用既有满载规则，核对所选名单和实际载货，输出必做事项。setup store收集事实，并用相同结果驱动完成度、确认与开始门禁；界面仅展示必做和可放弃两类清单。

新增6项引擎回归和10项store回归。后者包含剧本3/4/5/6的满载阻断、同额名单改选、必做西移不可放弃、双方确认/交接，以及两项真实行动链：剧本1轴方先手和剧本5苏方先手，从正式初设、必要卡车选择、双方确认推进到C，图上既有徒步单位合法走一格，验证进行中不能存、结束后能存读且位置/MP/结束标记保留。没有手改坐标、MP、阶段或创建替代单位绕过这条行动链。

正向开局测试共用`tests/flows/setup-harness.ts`，通过真实卡车点图与双方确认补齐前置；原有断言保留。加油专项仍按原边界缩小盘面验证同编队卡车付款，但先完成正式初设前置，并断言初设收束成功。

相关6个文件60项、引擎6项及最后2个文件17项回归通过。最终全量322个文件、4230项测试通过（2个工作进程，189.10秒）；类型、ESLint、全仓格式、架构检查与生产构建通过。构建保留既有大包提示，没有放宽测试阈值。

## 未验收范围

新首行动回归允许玩家按既有约定主动放弃普通未摆单位；没有据此宣称全部自由项、所有单位能力或完整回合的全部行动均已通过。界面分类、复选框变化和卡片标识没有人工浏览器签收；完整资源总账、启用时的SP装甲集群归属及其它单位首行动继续按S1/A批次验收。存档格式未变。
