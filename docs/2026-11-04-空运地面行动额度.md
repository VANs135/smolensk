# 空运地面行动额度与阶段资格

本轮按计划1B.4优先修复单位空运的准入和地面行动限制，依据OCS 14.9c/d、4.7d、5.4、5.6a、5.7b/e、5.10d及SOP。联合承运与部分返航仍列入1B.5。

## 原问题与结果

旧实现只在F步把半MA加进`mpSpent`，没有拒绝运输前已走超额度的单位；反应/进击仍套主移动数值，重复运输还会重复扣额度。单位模式直接读取原始`mode`，误拒已释放且朝移动面的预备，反而漏掉DG和进击等层叠标记。

本轮移除虚假MP预提。单位的`mpSpent`只表示实际地面消耗；宣布成功后记录独立的`airTransportThisPhase`，包含运输种类、阶段及装载时的预备释放事实。装载前生成完整额度计划，失败不离图、不扣SP、不消费骰子。

| 运输时阶段/单位              | 普通空运后该阶段地面总额度 | 同阶段攻击资格                           |
| ---------------------------- | -------------------------- | ---------------------------------------- |
| 主移动，合法移动模式         | 模式修正后MA的一半         | 仍遵守模式、SOP及突袭等具体动作条件      |
| 反应，已释放且朝移动面的预备 | 印刷MA的四分之一           | 仍遵守反应阶段行动与MP条件               |
| 进击，已释放且朝移动面的预备 | 印刷MA的一半               | 仍遵守模式、SOP及具体动作条件            |
| 反应/进击，普通移动模式      | 0                          | 不可攻击、突袭或进行炮兵轰炸             |
| DG、进击标记、未释放预备等   | 不得装载                   | 复用模式规则拒绝，不凭朝向或原始mode放行 |

单位空投仍须满足计划与资格，且该阶段不能消耗地面MP；因此任务前有任何实际地面消耗即拒绝。运输前后消耗合计不能超过相应额度，恰好用满额度仍能被运输，但落地后不能以最小移动再走一格。运输后保留已有的移动结束标记，不借空运恢复已结束的移动。

## 规则及状态边界

`engine/rules/air-unit-movement.ts`集中装载模式资格、阶段额度、重复运输和禁攻判断。装载资格复用`canUseTransport`，已释放预备按有效模式办理。普通重复空运只施加一次半MA限制；本阶段已空投的事实不能被另一趟普通空运放宽；装载时未释放预备的事实不能事后补标记解除。

移动与可达性、最小移动、突袭、统一合法性、正式战斗构成、攻击强度、炮兵轰炸及快速战果查看均读取运输限制；防守不受禁攻影响，空军任务继续独立。工作台只传递事实、提交已验证的义务，不另算移动比例。

“地面MP为0”与“尚未移动”分开处理。施工、基地缩减和移动前建造标记改用统一的已移动事实查询，不能因取消虚扣MP而把已空运的单位算成未移动；在途单位同样不能被移动前时点检查漏掉。

主动模式切换须在开始移动时，运输后不能借零地面MP重新切换。5.4中DG在主移动阶段可翻朝向的例外仍保留；运输事实在模式之外，翻面后也只能使用当前模式修正后的受限额度。运输后的地面移动可撤销，但只恢复真实MP和位置，不擦除运输事实。

宣布即提交运输义务，中止退运仍保留。相同阶段从移动切到轰炸/战斗环节不会清除它；仅换阶段、换方或换回合时按现有移动状态生命周期清理。死亡堆和重建返场也处理陈旧字段，避免新阶段恢复时继承旧运输限制。

额外修复验证页重复选择当前阶段会重置MP、飞机出动及卸载账本的入口。只有真实阶段变化才执行清理；比较真实会话阶段而非界面的回退显示，保证从`preTurn`选择进入移动阶段仍能正常执行。

## 保存与兼容

单位字段随现有完整盘面保存，格式保持v6。读取时明确校验运输种类、阶段与预备释放布尔值；非法字段拒绝，旧档缺少字段仍可载入。读档不重置有效义务，下一阶段才清理。

旧档中的MP原值保留，不猜测其中哪些来自旧版虚扣，不能事后可靠重建此前未记录的空运历史。任务中途保存仍受原有完整结算保护。
