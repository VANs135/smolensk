### 2.1 现状与原文冲突

- 原文（`ch03-axis-special-rules.md:31`）：**No Formation Consolidation（3.3d）**：轴心国**多单位编队**不能使用 Consolidation。
- 现实现（`src/stores/workbench.ts:17220-17235`）：`axisConsolidationRefused` 对**所有轴方**整编一律拒绝，并在日志引用**专规 3.2**（3.2 是 Luftwaffe 条款，与整编无关）。
- 后果：轴方 **29 个 Inf Div**（多军力、无编队）与**飞机**（不属于多单位编队）被过度禁止；
  `formation != null` 的 125 条轴方记录全是单军力，13.9-1 本就用不上，故"编队拒绝"分支无真实触发素材。
- 结论：**过严 + 编号误用**，以规则书为准修正为"仅多单位编队"。

### 2.2 精确改动

文件 `src/stores/workbench.ts`：

1. 删除 `axisConsolidationRefused(sides, action)`，改为：
   ```ts
   /**
    * 专规 3.3d：轴心国**多单位编队**不得整编（OCS 13.9）
    *
    * 判据：动作方或参与算子属轴方，**且**参与算子带编队番号（`formationId !== null`）。
    * 轴方独立单位（无编队）与飞机（不属多单位编队）不在本条限制内。
    */
   function axisFormationConsolidationRefused(
     input: { sides: readonly Side[]; formationIds: readonly (string | null)[] },
     action: string,
   ): boolean {
     if (!input.sides.includes('axis')) return false
     if (!input.formationIds.some((id) => id !== null)) return false
     pushLog(
       'warning',
       `专规 3.3d：轴心国多单位编队不得整编（${action}）—— 本动作被拒，未改动任何账本`,
       '专规 3.3d',
     )
     return true
   }
   ```
2. `consolidateUnitsNow`：先构造 `toConsolidationGroundView(keep/remove)`，再用其 `formationId` 判闸（不猜字段名）：
   ```ts
   const keepView = toConsolidationGroundView(keep)
   const removeView = toConsolidationGroundView(remove)
   if (
     axisFormationConsolidationRefused(
       {
         sides: [activeSide.value, keep.side, remove.side],
         formationIds: [keepView.formationId, removeView.formationId],
       },
       '合并多军力单位',
     )
   )
     return false
   ```
   随后 `planConsolidation` 继续使用 `keepView/removeView`（不改其它入参）。
