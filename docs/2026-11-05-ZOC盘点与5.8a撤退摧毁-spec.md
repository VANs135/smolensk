## 3. 选定断点与规则依据

规则原文（`_ocs_v43_clean.txt` 5.8a）：

> 单位不可在敌方 ZOC 内进入战略模式。处于战略模式的单位不可移动或撤退进入敌方 ZOC。如果被迫这样做（在撤退中），则单位会被摧毁。（如果是敌方单位移动到它们相邻处，不会发生任何特殊情况）

选它的理由：条款明确、单测可精确断言、不新增存档字段、只改 `battle.ts` 撤退判定与两处调用接线。

## 4. 精确改动

### 4.1 `src/engine/rules/battle.ts`

1. `resolveRetreat` 的 `unit` 入参新增可选 `strat?: boolean`。
2. 在撤退路径循环内、`9.12e` 的 EZOC 分支之前加入：

   ```ts
   // 5.8a：战略模式单位不可撤退进入敌方 ZOC；被迫如此 ⇒ 摧毁（DG 等 9.12e 后果不再适用）
   if (unit.strat === true && facts.inEnemyZocAt(next, unit.side))
     return { ...base, rule: '5.8a', hex: null, destroyed: true, gainsDg: false }
   ```

3. `resolveStackRetreat` 的 `units` 元素新增可选 `strat?: boolean` 并透传给 `resolveRetreat`。
4. `planRetreatDestinations` 入参新增可选 `strat?: boolean`；`forcedDestruction` 判定改为：

   ```ts
   forcedDestruction: clean === null ||
     input.immobile === true ||
     (input.strat === true && path.some((hex) => input.facts.inEnemyZocAt(hex, input.side)))
   ```

   仅标记为「必死落点」，不改变落点集合与路径搜索。
