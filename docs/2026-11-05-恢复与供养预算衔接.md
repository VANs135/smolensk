# A3第十三批：恢复与供养预算衔接

基线`833b638`。D段恢复处理结束后，尚为Low/Exhausted的单位仍可能在供养重算时再次产生恢复费用预留；但恢复账本已结算，不会再次执行该费用，导致供养预算虚减。

本批为纯计划`planSupplyPhase`增加可选`recoverySettled`事实。缺省仍按既有规则优先计划恢复；本阶段恢复已结算时不再次产生恢复分配，供养按当前实际可用补给计算。补给域传入既有`supplyRecoverySettled`阶段账本，新阶段reset后该事实恢复为false。没有新增存档字段或更改规则数值。

新增2项独立域回归。第一项构造仍为Low且恢复已结算的状态，核对恢复前2T恢复预留阻止供养、结算标记生效后重算不再预留，实际付款供养后不产生虚假损耗义务，重复重算及提交不再扣款。第二项核对阶段重置重新启用恢复优先。相关3个文件41项回归通过。

边界：用例构造阶段账本状态，付款通过显式端口记录，不等同于已完成所有多来源恢复/供养分配及真实界面连续回合验收。整体来源分配、资源总账和完整行动清单继续待验收，S1/R0未完成。两份原有未跟踪UI分析文档未改动、未提交。
