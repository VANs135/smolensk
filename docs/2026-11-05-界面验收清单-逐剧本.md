## 1. 统一进入路径

1. 打开应用（`npm run dev`，或既有 `serve:dist`）→ 左侧「初设与开局」面板。
2. 「剧本（唯一入口）」下拉选择目标剧本 → **自动初设固定格号/死亡堆/多点位**（见面板回执「待落位 N 项」）。
3. 地图左上「待你决定」队列逐项落位（候选为青柠色高亮格；未落位条目**视为本局移除**）。
4. 队列落满 → 点「完成初设」→ 建会话并进入回合准备。
5. 用顶部流程条推进：A 飞机/整备 → B 增援 → C 移动 → D 补给 → E 反应 → F 战斗 → G 进击 → H 清理。
6. 每一段结束前核对「待办/义务」清零，再进入下一段。

## 3. 逐条判据（每条点完看什么）

- **选剧本**：下拉切换后，初设回执出现「待落位 N 项」；固定格号的单位直接出现在图上；不应出现重复单位或空编队。
- **合法初设**：点「完成初设」前，待落位数为 0；点后出现会话、回合准备，且无法再改初设。
- **回合推进**：流程条按 A→H 顺序推进；未完成当前段义务时，下一段按钮不可用或给出规则号提示。
- **增援**：B 段列出到达单位与入场格；入场格不含铁路/超容量时拒绝并显示 13.6b/13.3b。
- **专规**：慢动员/装甲集群供给的限制对象与来源在面板可见；苏方慢动员的「应解锁量」只记录，不作判定（留白）。
- **战斗/撤退**：F 段 9.2 九步顺序不跳步；已付款后清场按钮被拒（不得取消逃逸）；撤退落点须完整距离（9.12），进 ZOC 按 9.12e 处理。
- **SP 运输**：选运输点数 + 同格补给站装载；超过运力（如 2 点卡车装 3 SP）必须被拒并提示 13.2c（本批已修，界面需复核提示是否可见）。
