## A6-11 13.8b 失能后可用自己架的桥离格 — 已实现

**条款**：13.8b（`_ocs_v43_clean.txt` L2530–2532）。

**原句**：「当单位不再具备工程能力时，架的桥就会消失。（例外：具有工程能力的单位在通过切换模式或朝向而失去工程能力后，**可以使用自己架的桥离开该格**。）」

**现状（修前）**：`bridgedHexesBySide` 只收"此刻有工程能力"的 HQ 所在格；切成移动模式后该格从清单消失，`MoveContext` 无按单位通道 ⇒ 这条例外整局不可达（该单位自己也被判成无桥）。

**改动**（`28f9837`）：

| 文件                                             | 改动                                                                                                                               |
| ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| `src/engine/rules/move-types.ts`                 | `MoveContext` 新增 `ownBridgeHexByUnitId?: Readonly<Record<string, HexRef>>`（按单位、瞬时、不进存档）                             |
| `src/engine/rules/move.ts#crossingForStep`       | 桥生效条件＝"本步出入格在架桥格清单" **或** "该单位自有桥格＝本步出格"；突袭仍由 `bridgedCrossing` 的 `forOverrun` 阻断            |
| `src/stores/workbench-model.ts#buildMoveContext` | 透传该字段（`createBattleFacts` **不传**）                                                                                         |
| `src/stores/workbench.ts`                        | `switchUnitMode` / `flipUnitOrientation` 前后比对 `engineerCapableNow`：由真变假记当时格；恢复能力或离格清记录；`moveContext` 注入 |

**为什么必须扩签名**：既有输入只有"按格集合"（无单位身份）与"布尔 `bridgePresent`"（全有/全无），无法同时表达"该格对其他人无桥 + 该单位离开时例外"。

**未扩的点（依据）**：原文只授权"离开该格"，未授权跨河**攻击** ⇒ `createBattleFacts` 不传该通道；初设（`setUnitModeAtSetup`）无既有桥可记；预备释放/DG 施加不构成"切换模式或朝向"且 5.10e 下 DG 朝战斗面仍具工程能力。

**断言**：先红（`tests/engine/own-bridge-13-8b.test.ts` 4 失败 / 1 通过）→ 绿（5 通过）；store 流 `tests/stores/bridge-terrain-flow.test.ts` 6 通过（含"同格卡车不能借、HQ 走离后记录清空"）。

**判定**：已实现；行为与原句一致，未外推。
