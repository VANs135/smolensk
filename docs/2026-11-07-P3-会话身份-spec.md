## 2. 展示契约（新增字段全部为投影）

```ts
export type MapSessionClosePolicy = 'cancel' | 'collapse' | 'refused'

export interface MapSession {
  kind: MapSessionKind
  /** 显示身份：`${kind}#${nonce}`；关掉重开同 kind 递增，换 kind 必变 */
  sessionId: string
  title: string
  rule: string
  width?: string
  /** 关闭语义（由 store 事实推出） */
  closePolicy: MapSessionClosePolicy
  /** 仅 `refused` 时给出原因（与领域拒绝文案同源） */
  closeBlockedReason?: string
}
```

`nonce` 规则：

- 初值 `0`；
- `watch(sessionBase.kind, { flush: 'sync' })`，`kind` 从 `null → kind` 或 `kindA → kindB` 时 `+1`；
- 同一 kind 存活期间无关重算**不**递增（重绘稳定）；
- `sessionId` 只在 `session !== null` 时存在。

`closePolicy` 映射（全部取既有事实，不新增规则判断）：

| kind         | closePolicy                                              | 依据             |
| ------------ | -------------------------------------------------------- | ---------------- |
| `combat`     | `combatCancelBlocker()` 非空 → `refused`，否则 `cancel`  | 9.2 已提交未完成 |
| `barrage`    | `barrageCancelBlocker()` 非空 → `refused`，否则 `cancel` | 10.0 已提交      |
| `move`       | `cancel`                                                 | 6.1 / 12.5c      |
| `air`        | `cancel`                                                 | 14.2f            |
| `supply`     | `cancel`                                                 | 12.6             |
| `unit`       | `collapse`                                               | 条 12（M2）      |
| `reinforce`  | `collapse`                                               | 13.5 / 13.6      |
| `breakout`   | `collapse`                                               | 12.8e            |
| `containers` | `collapse`                                               | 13.7             |
| `exclusive`  | `collapse`                                               | 专规动作         |

## 3. 改动清单（决策完整）

### 3.1 `src/stores/workbench.ts`

1. 新增并导出两个只读查询（放在 `canReplaceBarrage` 附近）：
   ```ts
   function combatCancelBlocker(): string | null {
     if (combatSupplyCommitted.value && combatState.value !== null && !combatState.value.finished) {
       return '战斗结果待结算：请先完成损失、选项、撤退与推进'
     }
     return null
   }
   function barrageCancelBlocker(): string | null {
     return barrageCommitted.value ? '轰炸已提交，请先完成掷骰和目标损失结算' : null
   }
   ```
2. `canReplaceBarrage()` 改为复用 `barrageCancelBlocker()`：非空时设 `barrageError = { rule:'10.0', reason:'barrageOutcomePending' }` 并 `pushLog('warning', blocker, '10.0')`，行为与现状逐字一致。
3. `cancelCombat()` 改为复用 `combatCancelBlocker()`：非空时 `pushLog('warning', blocker, '9.2')` 并 return，行为与现状一致。
4. 在 store 的 `return {}` 中导出 `combatCancelBlocker`、`barrageCancelBlocker`。

### 3.2 `src/stores/map-view.ts`

1. 抽出内部基础会话：把现 `const session = computed<MapSession|null>` 改名为 `sessionBase = computed<MapSessionBase|null>`（返回值**不带** `sessionId / closePolicy`），所有 return 分支不动。
2. 新增 `MapSessionClosePolicy`、`MapSessionBase`（内部类型）与扩展后的 `MapSession`。
3. 新增：
   ```ts
   const sessionNonce = ref(0)
   watch(
     () => sessionBase.value?.kind ?? null,
     (kind, previous) => {
       if (kind !== null && kind !== previous) sessionNonce.value += 1
     },
     { flush: 'sync' },
   )
   ```
4. 新增 `closePolicyOf(base)`：按 §2 表；`combat` / `barrage` 调 3.1 的查询，返回 `{ policy, reason? }`。
5. 新 `session = computed<MapSession|null>`：`{ ...base, sessionId: `${base.kind}#${sessionNonce.value}`, closePolicy, closeBlockedReason }`。
6. `cancelSession()`：
   - 进入后先取 `current = session.value`；若 `current.closePolicy === 'refused'`，仍调用对应领域取消（`cancelCombat()` / `cancelBarrage()`，保留其 warning 日志），但最终 `return false`（表示未真的取消）。
   - 新增 `breakout` 分支：`collapsedSessionKey.value = currentStepKey.value`（与 reinforce/containers/exclusive 同规），不再落入轰炸分支。
   - 其余分支保持现有调用不变。
   - 非 refused 时维持 `return true`。

### 3.3 `src/components/map/MapDock.vue`

1. 新增 props：
   ```ts
   closePolicy?: MapSessionClosePolicy  // 缺省 'cancel'
   closeBlockedReason?: string
   ```
2. 关闭按钮：
   - `cancel` → `title/aria-label = "取消本次操作"`
   - `collapse` → `"收起本次会话"`
   - `refused` → `"暂不可关闭"`，`disabled`，`aria-label` 带原因（有 `closeBlockedReason` 时 `暂不可关闭：${...}`）；不 emit `close`。
3. 不改拖动、位置记忆、隔离逻辑。

### 3.4 `src/views/GameTableView.vue`

```vue
<MapDock
  v-if="session !== null"
  :key="session.sessionId"
  :session-key="session.kind"
  :title="session.title"
  :rule="session.rule"
  :width="session.width"
  :close-policy="session.closePolicy"
  :close-blocked-reason="session.closeBlockedReason"
  @close="mapView.cancelSession()"
/>
```

`session-key` 保留 `kind`：位置记忆仍是「同一类型记住上次位置」，这是既定展示行为，不属于会话身份。
