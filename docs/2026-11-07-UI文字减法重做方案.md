# UI 重做方案 —— 文字减法与信息分层（2026-11-07）

> 依据：`2026-11-04-战鼓参考与兵棋UI优化计划.md`、`2026-11-04-兵棋UI设计规律与战鼓源码分析.md`、`2026-11-07-全操作冒烟与遗留问题归因.md`。
> 边界：只动 `src/components`、`src/views`、样式与只读投影；**不改 `src/engine`、`src/data` 判据**；不新增规则判定。
> 骨架默认保留：**地图为主 + 单一推进按钮 + 右栏只读 + 底部托盘**；本方案不动骨架。

## 1. 信息分层口径

| 层级 | 内容 | 形态 | 硬约束 |
|---|---|---|---|
| **L0 常驻** | 方/阶段/回合、当前待办、选中、MP/余额、唯一推进、阻断一句 | 一行短句 + 数字 + 图标 | 每条 ≤ 20 字；**条款号 0** |
| **L1 悬停/点开** | 这一步的代价、可选来源、覆盖范围、失败摘要 | tooltip、短标签、就地展开卡 | 每个标签 ≤ 12 字 |
| **L2 按需** | 规则原文、条款号、DRM、账本、履历、日志 | `?` 弹层 / 折叠区 / 底部日志 | 默认不出现 |

四条硬口径：
1. **一屏只留此刻必须看**：同一状态只出现一次（方/阶段不在顶栏、流程条、右栏各写一遍）。
2. **条款号不上主屏**：主屏只说动作词（加油、送达、解锁、撤退）；条款号只进 `?` 与日志，且从 `ACTION_GATES.rule` / `pushLog(rule)` 读取，不手抄。
3. **必要信息不隐藏**：可用态、阻断原因、代价、当前行动方/操作者，至少在一个稳定位置可查（L0 一句或 L1 点开）；折叠 ≠ 删除。
4. **数字上限**：主屏 L0 数字 ≤ 6（回合、日期、MP/余额、待办数、进度、1 个代价）；每个面板同屏数字 ≤ 6，其余进明细。

术语替换（主屏用右列，左列只进 `?`/日志）：

| 规则术语（L2） | 主屏短词（L0/L1） |
|---|---|
| 编队法 / 单独单位法 / HQ 法 | 整队加油 / 单枚加油 / HQ 加油 |
| 投递 / 拖取 | 送达 / 直取 |
| 追溯补给 / 断补 | 查补给 / 缺补 |
| 慢动员（专规 2.4） | 解锁师 |
| 损耗分摊 / 损失选择 | 分损失 / 选损失 |
| 战术模式 / 移动模式 | 战术 / 移动 |
| ZOC / 控制区 | 控制区（首次悬停给全称） |

## 2. 目标形态

```
┌──────────────────────────────────────────────────────────────────────────┐
│ ① 流程条：苏方 · 增援 · 放置 2/3      [推进 ▸]        [对手] [图层] [AI] [?] │
├──────────────────────────────────────────┬───────────────────────────────┤
│ ② 地图（唯一主体，≥75% 宽）               │ ③ 右栏（只读、按需）          │
│   · 堆叠就地展开（点选）                  │  状态卡（一行）               │
│   · 会话框只在需要输入时出现（一个）       │  待办卡（仅非空）             │
│   · 悬停短标签（L1）                      │  所选卡（名称 + 3 个关键数）  │
│                                          │  ▸ 战况  ▸ 专规（折叠）       │
├──────────────────────────────────────────┴───────────────────────────────┤
│ ④ 底部托盘：▸ 盒   ▸ 表格（各一行；同时只展开一段）                        │
└──────────────────────────────────────────────────────────────────────────┘
```

- **顶栏**：文字标签 14 → 3（`苏方·增援`、`回合/日期`、`推进`），其余图标 + tooltip；图层 5 勾选 + ZOC 收进「图层」弹层。
- **右栏**：7 个常驻面板 → 3 张卡 + 2 个折叠入口；`ReinforcementPanel only="info"` 只在增援阶段出现；胜利面板只在终局出现；快捷键只从 `?` 进。
- **会话**：同一时刻最多一个；关闭即回地图，不占常驻宽度。
- **底部托盘**：默认折叠为两行；展开只开一段。

## 2A. 交互重做规格（2026-11-07 补充，**替代常驻操作面板**）

> 本节的优先级高于 §2/§3 里任何「常驻面板」表述。U1 及以后全部按本节实现；U0 只做死入口与文案，不受影响。

### 2A.1 三层归位（修正版）

| 层 | 常驻？ | 内容 |
|---|---|---|
| **L0 状态** | **常驻** | 分数（胜利格控制，见 2A.7）、回合/日期、环节/阶段、行动方/操作者、**唯一推进按钮**、一句阻断提示 |
| **L1 操作** | **点开才出现** | ① 本环节「可做的事」清单 → 点一项弹出对应**会话框**；② 点格子/算子；③ box 展开；④ 空军基地展开；⑤ 右键菜单 |
| **L2 按需** | 折叠/悬浮 | 条款号、规则原文、明细、账本、日志 |

- **除「增援」外**，所有环节不再常驻功能面板：本环节先列「可做的事」，点某项才出现该操作的会话框。
- **增援**保留常驻面板：到达落位 / 重建整编 / 编队抽取 / 特殊补员 / 慢动员是**批量流程**，逐项弹框反而增加点击数。
- 同一时刻**最多一个会话框**；关闭即回地图。
- 会话框只承载「本次操作」：输入项、代价、可用态、占一个主按钮；规则原文进 `?`。

### 2A.2 每环节的「可做的事」与会话框触发点

| 环节 | 清单项（L1） | 点开后 |
|---|---|---|
| 初设 | 落位、自动初设、编内卡车、装甲集群归属 | 落位会话框（点算子→点格）；其余为一步式确认框 |
| 移动 | 移动/突袭、加油、改模式、铁路运输、装卸 SP、运输点合并拆分、建/修基地、修工事、销毁补给站、运输点⇄延补队 | 选中堆叠后点清单项 → 只弹该项会话框；地图保持可点 |
| 补给 | 拖取/投递、全场追溯判定、断补损耗处置、恢复部队储备、Forage | 选中来源/受补给单位 → 会话框（来源与受方各一块） |
| 战斗 | 宣布战斗、突袭、九步结算、一键查表 | 点目标格 → 战斗会话框（模式切换在框内） |
| 轰炸 | 宣布轰炸、低空扫射 | 点目标格 → 轰炸会话框（空军任务不进本面板） |
| 空军 | 整备、任务分配、缩减基地 | **点空军基地算子**展开该基地飞机 → 点飞机 → 会话框 |
| 增援 | （常驻面板） | 面板内逐项按钮，不弹框 |
| 突围 / 分界线义务等 | 清单项只在对应环节出现 | 一步式确认框 |

### 2A.3 格内堆叠排布与缩放

- 堆叠**在格内摊开**，不用列表弹窗；玩家可点**具体算子**，也可点**格子**。
- 左键点格：**优先把战斗单位作为堆叠主体**（4.8b：有 ZOC 的战斗单位在最上）；非战斗单位**单击选择**，不抢堆叠主体。
- 格内排布（12×12 格基准，格子约 96px）：

| 枚数 | 排布 | 单枚视觉尺寸 |
|---|---|---|
| 1 | 居中 | 100% |
| 2 | 左右并列 | 74% |
| 3 | 品字（上 1 下 2） | 68% |
| 4–5 | 2×2 / 2×3 网格 | 58% |
| ≥6 | 3×2 网格 + 角标「+N」 | **50%（下限）** |

- 视觉下限 50%，**命中区不随视觉缩小**：每枚算子的点击热区 ≥ 24×24px（CSS 绝对定位按钮，padding 补足），缩放后仍能准确选中。
- 命中优先级：**视觉最上层 = 堆叠最上层**（按 4.8b 顺序绘制，后绘制者在 z-index 上层）；重叠区域归最上层；格内空白区域 = 选中整格。
- 地图缩放：**0.8× ～ 2.0×**（按钮 `+/-`、`0` 适应窗口；本次不做滚轮缩放与触屏）。
- 放大后格内算子按上表比例跟随缩放，但**命中热区仍按屏幕像素 ≥24px 兜底**。

### 2A.4 右键菜单（收纳小众功能，主界面不占位）

| 分组 | 菜单项 | 规则出处 |
|---|---|---|
| 运输 | 装载 / 卸载 SP；合并 / 拆分运输点数；运输点 ⇄ 延补队 | 13.2f / 13.2c / 12.7a·d |
| 工程 | 修建 / 改进基地；修建 / 缩减环形工事；换轨 | 15.3 / 16.0b·c / 13.x |
| 编组 | 创建拆分单位；编队收纳盒「收纳 / 放出」 | 3.x / 13.7 |
| 补给 | 销毁己方补给站；Forage（就地取给） | 12.11a / 12.x |

- 菜单项**仍受 `ACTION_GATES` 的阶段/方/可用态约束**：不满足的项灰显并给一句阻断原因；不新增判据。
- 右键只对**已选中**的格子/算子生效；空白处右键 = 关闭菜单。

### 2A.5 空军与 box 的展开

- **空军**：点**空军基地算子**才展开该基地内的飞机列表；点飞机 → 整备 / 任务分配 / 缩减。
- **地图外空军盒**：同样的展开式列表（盒不常驻，点开才出现）；盒内飞机与基地内飞机共用同一套动作。
- **其他 box**（地图外盒、边缘盒、编队收纳盒、死亡堆）：**只在对应环节由玩家自己展开**；点击其中单位即选中并交互，不常驻。
- 收纳盒内单位仍是「迷雾」：对手视角不显示内容（见 2A.6）。

### 2A.6 对方视角与战雾（只做展示层降级，不造侦察规则）

**原文核查结论**：
- 通规 **4.9a**：不能检查敌方堆叠；只能看**环形工事**、**最上方战斗模式的可攻击单位**（若全堆叠无 ZOC 则看最上方战斗单位）、**最上方激活飞机**；可得知最上方单位的**战略模式 / DG / 断补**，但**无权知道部队储备与损失军力**。
- 通规 **4.9b**：战斗中双方展示 AR、反坦克效果、战斗值总值，**不必展示实际单位**。
- 通规 **4.9e**：掷骰默认公开，经双方同意才可秘密。
- 专规 **1.4**：地图外盒「双方同意可隐藏」。
- **13.7** 是编队标记/收纳盒（收纳下属以制造迷雾），**不是通用侦察规则**。
- **本作没有「侦察/探测」可执行判据** ⇒ 不新增侦察规则，只做展示层裁剪。

**展示层降级口径**（全部消费现有只读投影 `fog.ts` / `visibleUnitIds`）：

1. 对方堆叠只显示 4.9a 允许的公开事实：工事、最上方可攻击战斗单位、最上方激活飞机、ZOC 是否产生。
2. **不显示枚数**（`stackSizeHidden`），不显示「+N」；不显示部队储备、损失军力、内部库存。
3. 编队收纳盒 / 地图外盒按专规 1.4 默认可见；**只有双方显式同意隐藏**时才隐藏内容（沿用现有模式开关，不新造开关）。
4. 战斗/轰炸会话框只公开数值合计，不列对方算子明细。
5. 边界：不改切方与热坐交接流程，不改任何裁定；若原文没有可执行判据的场景（如「侦察到某格」），一律**不实现**。

### 2A.7 L0 分数：用现有投影，不现算

- 现有 store 已有 `victorySummary`（`listedBySide` / 逐城 `held`）与终局 `evaluateFinalVictory`。
- L0 常驻显示 **「胜利格 轴 N・苏 M」**（读 `listedBySide`）；终局才显示胜负结论。
- **不新增 VP 数值、不新增计算**；若后续原文确有点数化 VP，再加只读投影。

## 6. 风险与回滚

- **藏得太深**：每张卡保留 `?`；被砍原文全部可从 `?`/日志/折叠区到达，不删除能力。
- **老玩家找不到**：保留快捷键 H/?/S，图标按钮 tooltip 写明。
