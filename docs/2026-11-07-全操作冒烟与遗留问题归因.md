## 3. 引擎问题清单

### 3-1 `payFuel` 无目标拒绝缺条款号（已修，红→绿）

- 现象：未选目标时 `pushLog('warning', '先选中要加油的单位…')` 缺第 3 实参，操作台日志无法回指条款。
- 用例：`all-actions-smoke.test.ts` → `payFuel（无选中目标）`（修前失败：`rule` 为空）。
- 修复：`workbench.ts:7024` 补 `'12.5'`。回归：冒烟 55/55，全量见 §0。
- 影响面：仅日志可审计性，不改判据、不改状态。

### 3-2 `legalActionsView` 的「available 但无提交入口」（未修，记录）

- `rein.formationDraw`、`rein.specialRepl` 在 `SUBMIT_ENTRY_OF` 为空串却可 `available`，`note` 已写「无既有提交入口」；`exclusive.panzerObligation` 同（由段末收束）。
- 现状不构成玩家缺陷（该投影当前不渲染到玩家界面）；若 AI/未来 UI 按 `submit` 直调会落空。列入 UI/投影清单，不本轮改。
