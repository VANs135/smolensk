### 4.2 安装器日志里的失败原因

`C:\Users\KD\AppData\Local\Temp\dd_setup_20261108123252_errors.log` 与主日志：

```
System Measurement for 'InstallOperation': 'System Drive Space (Before)': 654589952   (≈624MB)
System Measurement for 'InstallOperation': 'Target Drive Space (Before)': 125871263744 (≈117GB)
Error: Pre-check verification: Visual Studio needs at least 3.46 GB of disk space.
       Try to free up space on C:\ or change your target drive.
Prompting: Failed pre-checks: [SizePreCheckEvaluator, ...]
Selection: Cancel
Error 0x80070070: Pre-check verification failed with error(s) : SizePreCheckEvaluator.
```

**根因：VS 安装器对「系统盘」有 3.46GB 的硬门槛，即使 `--installPath` 指向 E 盘也不放宽**
（安装器本体、共享组件与解包缓存仍要求系统盘余量）。C 盘当时只有 ~620MB，因此被拦下。
退出码口径 `0x80070070` = `ERROR_HANDLE_DISK_FULL` 家族的磁盘不足。

### 4.3 结论

「装到 E 盘」这条路在磁盘层面可行，但**卡在安装器自己的系统盘检查上**，不是路径配置问题。
本机需要先把 C 盘腾到 ≥3.5GB 才能走这条路。

## 9. 安装脚本（管理员 PowerShell 执行）

版本化路径：`D:\OCS\smolensk\scripts\install-vsbt-elevated.ps1`
（同内容已复制到 `E:\temp-install\install-vsbt.ps1`，UTF-8 BOM 保存，PS 5.1 可正确解析）

脚本行为：

1. **断言系统盘 ≥4GB**，不足打印 `ABORT` 并 `exit 2`（不写注册表、不安装）
2. `SharedInstallationPath` = `E:\VSBuildTools\Shared`（先存原值再写）
3. `TEMP`/`TMP` = `E:\temp-install`
4. `winget install Microsoft.VisualStudio.2022.BuildTools`
   `--override "--wait --passive --installPath E:\VSBuildTools --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"`
5. 装完打印 `vswhere`（含 `VC.Tools` 限定与全量 JSON）、`E:\VSBuildTools` 是否生成、
   C/E 余量、SDK 目录位置；结果写入 `E:\temp-install\vsbt-install.log`

运行方式（管理员 PowerShell，一条）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\OCS\smolensk\scripts\install-vsbt-elevated.ps1
```

等价的手工两条命令：

```powershell
reg add "HKLM\SOFTWARE\Microsoft\VisualStudio\Setup" /v SharedInstallationPath /t REG_SZ /d "E:\VSBuildTools\Shared" /f
$env:TEMP='E:\temp-install'; $env:TMP='E:\temp-install'
winget install --id Microsoft.VisualStudio.2022.BuildTools -e --accept-package-agreements --accept-source-agreements --override "--wait --passive --installPath E:\VSBuildTools --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"
```

## 10. 彻底卸载（把整套 E 盘工具链清掉）

```powershell
# 1) 环境变量（用户级）
[Environment]::SetEnvironmentVariable('RUSTUP_HOME',$null,'User')
[Environment]::SetEnvironmentVariable('CARGO_HOME',$null,'User')
[Environment]::SetEnvironmentVariable('CARGO_TARGET_DIR',$null,'User')

[Environment]::SetEnvironmentVariable('Path',$p,'User')
# 3) 目录
Remove-Item -Recurse -Force 'E:\rust','E:\npm-cache','E:\temp-install'
# 4) VS 部分：设置 → 应用 → 卸载 "Microsoft Visual Studio Installer" / "Visual Studio Build Tools 2022"
#    再删注册表共享路径（见第 3 节）
```
