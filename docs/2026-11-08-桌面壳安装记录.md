## 4. VS Build Tools + Windows SDK —— **阻塞**

### 4.1 失败环节

| 项 | 值 |
| --- | --- |
| 命令 | `winget install --id Microsoft.VisualStudio.2022.BuildTools -e --accept-package-agreements --accept-source-agreements --disable-interactivity --override "--wait --passive --installPath E:\VSBuildTools --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"` |
| 退出码 | `1602`（winget 侧 `-1978335226`） |
| 说明 | winget 已成功找到包（17.14.44）、下载并校验 `vs_BuildTools.exe`，在**启动安装程序**阶段被取消 |
| 磁盘 | 安装前后 E 盘 117.24GB → 117.24GB（未落盘），C 盘 1.09GB |

### 4.2 根因

当前进程**非提权**（`IsAdmin=False`；`whoami /groups` 显示 `BUILTIN\Administrators` 为
"Group used for deny only"）。账户 KD 在管理员组内，因此只能走 UAC 提权。

UAC 提权共尝试 **3 次**，全部失败：

| 次数 | 方式 | 结果 | 耗时 |
| --- | --- | --- | --- |
| 1 | `Start-Process -Verb RunAs` 运行 `install-vsbt.ps1` | `The operation was canceled by the user` | — |
| 2 | 同上 | 同上 | 122.2 s |
| 3 | 同上（按用户要求延长等待） | 同上 | 122.2 s |

第 2、3 次都稳定停在 **122.2 秒**后被取消，`consent.exe` 未驻留，三次耗时一致 ——
说明是**系统侧在约 2 分钟后自动取消了提权请求**，不是有人点了「否」。
UAC 策略本身正常：`EnableLUA=0x1`、`ConsentPromptBehaviorAdmin=0x5`。

即：**这一步在当前会话内无法完成，与 C 盘空间无关**（B 路径的磁盘问题已用 E 盘绕开）。

### 4.3 需要的操作（用户侧，一条）

在**管理员 PowerShell**（开始菜单搜 PowerShell → 右键「以管理员身份运行」）里执行：

```powershell

$env:TEMP='E:\temp-install'; $env:TMP='E:\temp-install'
winget install --id Microsoft.VisualStudio.2022.BuildTools -e --accept-package-agreements --accept-source-agreements --override "--wait --passive --installPath E:\VSBuildTools --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"
```

或者直接以管理员身份运行已备好的脚本（内容与上面两条等价，且带 transcript 日志）：

```powershell

```

装完后我从「校验」一步接着做，不需要再提权。
