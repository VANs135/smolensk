### ⑦-3 点选对象、取舍顺序与可点判据

**原则：不新造优先级。** 规则里的取舍顺序已由 12.5c-A/B/C 与 12.x 投递关系确定；
界面只做「**按现行分组呈现 + 选中即提交**」。同格确实存在规则未规定先后的并列来源时，
记录为「**并列，由玩家点选**」，不自己定胜负。

| 对象                                | 可点判据来源                                                          | 同格多来源的呈现                                              |
| ----------------------------------- | --------------------------------------------------------------------- | ------------------------------------------------------------- |
| SP（补给点）                        | `supplySources` 中该受补给单位可用的来源（引擎已给可用/不可用与原因） | 按 `supplySources` 的既有分组原样呈现；同组内并列即由玩家点选 |
| HQ（指挥部投递）                    | 12.3b 投递距离内的 HQ（`supplySources` 已判）                         | 同上                                                          |
| 载体 / 延补队 / 基础源 / 吃图上补给 | 12.7 / 12.6a / 12.6c（引擎已判）                                      | 同上                                                          |
| 付款补给站                          | `supplyPayDumpCandidates`（引擎已筛）                                 | 点同一座即回到「自动」（沿用 `toggleSupplyPayDump`）          |

- **不可点**：不在 `supplySources` / `supplyPayDumpCandidates` 里的对象不响应；被拒时只给**一行**原因（条款号收进 `RuleTip`，不铺长文）。
- **并列口径（本次定稿）**：同格多座可用来源若规则未规定先后 ⇒ **并列**，界面同时高亮，点哪座用哪座；不按"最省/最近"自行排序。
- 与 12.5 加油的关系：12.5c-A/B/C 决定"这一笔算编队法、HQ 法还是单独单位法"，加油入口 `payFuel` 不变；地图点选只替换"选哪座源"。
- 与 12.x 投递的关系：12.3b 投递的"投给谁"仍是当前受补给单位（已确定），地图点选只选**来源**，不改变投递对象。

### ⑦-4 误点与取消 / 保留的面板信息

- 误点：点空白格 = 不动作；点不可用来源 = 一行原因；再点已选来源 = 取消（与 `toggleSupplyPayDump` 同口径）。
- 面板保留：受补给单位、来源分组、付款后余额（SP 剩余）、应付 T 数与费率、`RuleTip` 条款提示；**删除**解释性长段。
- 依赖：地图选格复用 `beginHexPick` / `pickHexFor`；来源高亮复用 12.3d 预览的既有路径。

### ⑦-5 验收

1. 进入补给判定后，地图高亮**仅**可用的来源格（与 `supplySources` 一致，不多不少）；并列来源同时高亮，不做隐式排序；
2. 点格即选定来源，面板同步显示已选来源与余额；再点取消；
3. 不可用来源点不动，只出一行原因；
4. 12.5 加油、12.3b 投递、12.6c 吃图上补给三条路径的判定结果与改造前**完全一致**（同一引擎入口，仅入口形式变化）；
5. 按方过滤：非当前行动方的内容不出现（接 ② 口径）。

- 是否需数据或字段：**否**（判据全部来自既有 `supplySources` / `supplyPayDumpCandidates`）。
