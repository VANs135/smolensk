## 1. 14.7d 低空扫射

### 1.1 原文摘录（`_ocs_v43_clean.txt` 2874–2885）

> 14.7d 低空扫射。**低空扫射在移动环节中进行。** 结算方法与普通轰炸 (14.7)相同，但有一些例外和限制：
> A) 低空扫射不计入每个阶段内对一个格最多一次轰炸的限制。这就意味着，在一个阶段内，一个格可以被多次低空扫射，此外还可以在同一阶段内承受一次“常规”轰炸。
> B) **低空扫射必须由单独一个飞机完成**，且在游戏专属规则手册中，必须说明**该国籍的飞机**具有特殊的低空扫射能力。
> C) 低空扫射需要一个正确的观察员 (10.0b)。
> D) 鉴于上述情况，低空扫射可以攻击任何类型的目标。(例外：运输破坏不能作为低空扫射进行)。

补充原文：

- `_ocs_v43_clean.txt` 2690–2694：「低空扫射是在**移动环节**而非轰炸环节中进行的一种特殊类型的轰炸……只有某些国家的空军可以进行低空扫射，这将在游戏专属规则中注明。」
- `_ocs_v43_clean.txt` 1583–1588（10.0b）：「进行低空扫射（**无论使用哪张表**）都需要有正确的观察员。」
- `_ocs_v43_clean.txt` 2891（14.8）：「这些任务（运输破坏）不能作为低空扫射执行。」

| 项            | 原文结论                                                                                                                                                                         | 出处                       |

## 2. 14.11 基地转移

### 2.1 原文摘录

- `_ocs_v43_clean.txt` 2701–2702（14.2e 任务清单）：

> 基地转移 (14.11)。将飞机从一个空军基地移动到另一个空军基地。**转移可在不同的移动环节中执行。**

- `_ocs_v43_clean.txt` 3029–3035（14.11 正文）：

> 14.11 基地转移
> 基地转移是将飞机从一个基地转移到另一个基地的简单方法，但飞机不能执行任何其他功能。空军单位从一个基地转移到另一个基地时，**距离可增加一倍**。
> 当一个战斗机单位在正常距离内执行基地转移时，它将**保持激活状态**。如果超出，它将进入**非激活状态**（如同其他进行基地转移的其他类型的飞机那样）。

### 5.1 第 1 条改法（C 移动环节只放行空军低空扫射）

关键在于**段（phase）分不出“轰炸环节”与“移动环节”**，必须把**环节 id** 带进引擎判据：

1. `src/engine/rules/barrage.ts#barrageEligibility`
   - 入参增加可选 `segment?: string`（SOP 环节 id）。
   - 在阶段门槛之后加：`segment` 以 `.modeAndMovement` / `.movement` 结尾（移动环节）时，只允许 `kind === 'air' && hipShoot === true`，否则返回 `{ ok:false, rule:'10.0', reason:'movementSegmentOnlyHipShoot' }`。
2. `src/engine/rules/barrage-interaction.ts#beginBarrage`
   - 入参增加可选 `segment`，原样传给 `barrageEligibility`。
3. `src/stores/workbench.ts#beginBarrageNow`
   - `beginBarrage({ ... })` 传 `segment: segmentStep.value?.id`。
4. `src/stores/workbench.ts#barrageKindsInSegment`
   - 去掉“非轰炸环节给全量”的旁路：
     - 轰炸环节：按 `BARRAGE_SOURCES_BY_PHASE[phase]` 过滤（C 段仍 `air`/`ship`）。
     - 移动环节：只返回 `['air']`。
     - 其余环节：返回 `[]`。
5. `src/stores/map-view.ts` 右键「炮击」
   - 既有两判据外再加 `workbench.barrageKindsInSegment.includes('artillery')`（本作无舰船；空军轰炸/低空扫射走空军任务链，不经这个入口）。
6. `src/stores/workbench-model.ts` + `src/stores/action-families.ts`
   - 给 `barrage.declare` 的 `movement.modeAndMovement` 条目补 `note`：「10.0 第二段：移动环节仅『有低空扫射能力的空军单位』可轰炸；火炮/舰船不得参与」。
   - 动作族表行带出该 `note`（`ActionGateWhere` 与 `ActionFamilyRow` 各加一个 `note?: string / string | null`）。
7. 测试（先红后绿）：
   - `tests/engine/barrage.test.ts`：移动环节下 `ship`/`artillery`/无 `hipShoot` 的 `air` 拒；`air + hipShoot + 观察员 + 单机` 通过；`movement.barrage` 下普通空军轰炸仍通过、5 机仍 `tooManyAircraft`；火炮 12 单位通过。
   - `tests/stores/context-menu-capabilities.test.ts`：C 移动环节与 C 轰炸环节，带轰炸值的火炮都没有 `barrage.declare`；F 轰炸环节仍有。
   - `tests/stores/action-family-table.test.ts`：移动环节行的 `note` 含「10.0 第二段」「移动环节仅」。
   - **不改** `tests/flows/30-phase-c-movement.test.ts` 与 `tests/engine/legality.test.ts`：它们断言的是 C 段**轰炸环节**的 `air & ship`，与 10.0 第一段一致。

> 注：`ACTION_GATES['barrage.declare']` 在 `movement.modeAndMovement` 的条目**保留**（低空扫射仍属 10.0 轰炸）；只是入口收窄到空军任务链 / 右键敌方格（`hipShootEntryEligible`），地面「炮击」按钮在该环节不出现。
