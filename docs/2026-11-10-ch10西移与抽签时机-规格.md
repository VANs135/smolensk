## 2. A1 引擎：沿 road 三格

`src/engine/rules/containers.ts`

```ts
export type RoadEdgeQuery = (from: HexRef, to: HexRef) => boolean
export interface ShiftWestWalk {
  hex: HexRef
  walked: number
  exact: boolean
  path: readonly HexRef[] // 含起点
}
export function shiftWestDestination(
  from: HexRef,
  steps: number,
  hasRoad: RoadEdgeQuery,
): ShiftWestWalk
```

- 每步只在西向两邻（`SW`、`NW`，均 col−1）取：须 `isOnMap` 且 `hasRoad`；两者皆可时固定 `SW → NW`。
- 都不可 ⇒ `break`，`exact=false`、`path` 保留已走部分。
- 不读文件、不「视为有道路」。
