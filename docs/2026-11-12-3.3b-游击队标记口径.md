# 3.3b 游击队/运输破坏标记口径（2026-11-12 确认）

> 本文件固定 3.3b 的执行口径，避免后来人按「或」理解。代码注释同步落在
> `src/engine/rules/security-needs.ts`、`src/engine/rules/cleanup.ts`、
> `src/stores/workbench.ts` 的 `applySecurityNeedsNow`。

## 原文（专规 3.3b，`Smolensk_Rules_v1.1.txt` 381–390 行）

> 轴心国控制的城市格（按 5.0c 定义）应由一个 **Attack-Capable** 单位占据或被 **ZOC** 覆盖；
> 否则在该格放一个苏军 **Trainbusting** 标记（代表游击队活动）。
> 标记可在**任意相位**放置；在**任意 Clean Up Phase**，若安全需求满足或该城转为苏军控制则移除。

## 确认口径

1. **轴心占领即轴心控制**。城市已被轴心占领，就按轴心控制城市参与 3.3b 判定；不再另设控制推演。
2. **放置条件（缺一不可）**：轴控城市
   - **没有被具备攻击能力的轴心单位占据**，**且**
   - **不处于轴心控制区 ZOC 内**，

   两条同时成立才放游击队/运输破坏标记。只要占据或 ZOC 覆盖有一条成立，就不放；不是「或」。

3. **放置时机**：任意阶段，**手动**执行治安检查；**不**随阶段开始自动触发。
4. **移除检定只在清理阶段（H）**：其它阶段即使执行治安检查，也不会移除标记。
   满足「有具备攻击能力的轴心单位占据，或处于轴心 ZOC 内」或「该格重新被苏联控制」时移除。
5. **放置理由字段**：标记带 `cause`（`securityNeeds` / `airMission`）。只有 `securityNeeds`
   标记按上述条件移除；空军任务标记仍按 10.0c-C / 14.8c 在下一个敌方清理阶段无条件移除。
