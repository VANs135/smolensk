## 0. 已定边界

1. **所有主动空军任务以目标为主**：轰炸、低空扫射、空运、空投、破交、扫荡，全部右键**目标** → 出对应菜单 → 窗内按基地分组列航程内可参与飞机 → 多选组队 → 确认。
2. **多基地组队**由此自然表达（14.2f：来自多个空军基地，最多 4 个空军单位）。
3. **炮击 / 轰炸 / 低空扫射共用同一射击菜单**与同一套候选生成逻辑（`counterActionsAt` → `OpsFlowPanel`）。
4. **返航被动**：任务结算完成后自动进入返航三选一；不提供主动返航入口。
5. **整备已实现**：只把支付段接到与炮击同源的统一支付流程，不重做整备逻辑。
6. **进出图外盒 = 转场**：基地窗选中飞机 → 两个子项「进入地图外盒」「放入别的空军基地」；盒内单位只能转入图上基地，不提供盒到盒。
7. 目标格与目的基地一律**地图高亮点选**，不手输、不下拉。同类对象只留一个入口，不置灰，不带条款号。

## 1. 目标侧发起的交互（定稿）

### 1.1 有敌方目标的任务

1. 右键敌方堆叠 / 设施（或铁路格、有敌方激活空军的空军基地格）；
2. 选择任务子项（炮击 / 轰炸 / 低空扫射 / 扫荡 / 破交）；
3. 任务窗左侧按基地分组列出**所有航程内**可参与飞机（含跨基地、含图外盒）；
4. 多选组队（14.2f 上限 4 架）；
5. 确认执行。

**跨两基地扫荡的点击数**：右键目标 1 → 点子项 1 → 勾 A 基地 1 架 + B 基地 1 架 2 → 执行 1 = **5 次**。

### 1.2 空运 / 空投

1. 右键**目标格**：空运＝己方空军基地格；空投＝无敌方地面单位的投送格；
2. 选「空运」/「空投」；
3. 窗内按基地分组选机（运输能力由引擎闸）；
4. 执行。

**跨两基地空投的点击数**：右键投送格 1 → 空投 1 → 勾两架 2 → 执行 1 = **5 次**。

### 1.3 候选与高亮

- 候选＝**任务对象类型合法**（14.6–14.10）∩ **参战机航程可达**（14.2d / 1.4a）；
- 全部由引擎 `airMissionTargetCandidates` 统一算，UI 只渲染；
- 已勾选编队时按 `every`（每架都要够得到）；未勾机时按 `some`（至少一架可参战机够得到）；
- 窗内基地分栏只列**机型能执行该任务**的飞机（不能执行的整架不出现，不摆灰项；`airTypeCanPerformKind`）；
- 图外空军盒不是地图格，且 1.4 禁止对盒内战斗 ⇒ 永不进入目标候选（无专规例外）。

## 2. 没有目标的任务从哪里进

1. **返航**：任务结算完成后自动进入 ⑥ 步三选一（出发基地 / 图外基地（航程够才出现）/ 剩余航程内其它己方基地）。不提供主动入口。
2. **整备**：整备阶段点己方空军基地格（基地窗）或图外盒盒卡；见第 5 节核对。
3. **转场（14.11，含进出图外盒）**：基地窗选中飞机 →「进入地图外盒」/「放入别的空军基地」；盒内选中飞机 →「转场到基地」（只转入图上基地）。
4. 无「空战 / 拦截」主动入口：它们发生在任务流程的空战步与拦截步，由任务会话处理。

## 3. 防区外 / 航程边界怎么展示

1. 任务窗按基地分组，组头显示基地格与可动用飞机数；
2. 每架机一行：`机型 | 航程 R | 到目标距离 D | 够/不够`；`D > R` 不可勾选并写明差多少格；
3. 勾入超程飞机时，已选目标立刻标红并禁止执行，不等到点「执行」才报错；
4. 筛选与判定在引擎侧，UI 不自算。

## 4. 编队航程（原文核对）

原文 14.2d：

> 「……把每个参战飞机放在**其自身航程**内、距任务格不超过航程的位置。」

- 每架飞机从自己的出发基地/位置起算，各自与任务格比较；
- 原文**没有**「编队取最低航程」或「先集结再出发」的规定；
- 实现口径：编队内每一架都必须独立够得到（已勾机时 `every`）。

标注：**实现口径，原文未写「取最低航程」**；若要改口径需用户另行指定。

## 6. 空军任务是否需要补给（原文核对）

**结论：除炮击与整备外，所有空军任务都不支付补给。**

1. 14.7a：「空军轰炸本身从不需要任何补给消耗。轰炸是一种特殊弹药，飞机的军力代表该型飞机的弹药量。」
2. 14.7d：低空扫射按 14.7 轰炸规则结算 ⇒ 不支付补给。
3. 14.9 / 14.10：空运、空投运送的是货物（SP/单位），不是付款。
4. 10.1b：只有地面炮击需要从补给站支付。
5. 15.1B：只有整备需要 1T。

因此共用骨架中，**支付段按操作类型装配**：炮击有、整备有、其余空军任务没有（不是默认带出再隐藏）。

## 7. 转场（14.11 / 1.4a）原文与口径

原文 14.11：

- 转场是把飞机从一个空军基地转到另一个空军基地；
- **转场距离可增加一倍**；
- 战斗机在正常航程内转场保持激活；超过正常航程但不超过双倍航程，转入非激活；
- 转场不计为执行过一次任务。

专规 1.4a：

- 地图外空军盒与地图之间移动，按 **20 格（苏）/ 30 格（轴）** 航程计算，并加与盒连接列的列差；
- 1.4：盒内**不允许战斗与轰炸**。

实现口径：

| 动作        | 航程判据                  | 状态                             |
| ----------- | ------------------------- | -------------------------------- |
| 基地 → 盒   | 1.4a：20/30 + 列差 ≤ 航程 | 移入后按 1.4a 归位               |
| 基地 → 基地 | 14.11：距离 ≤ 航程 × 2    | 正常航程内保持激活；超过则非激活 |
| 盒 → 基地   | 1.4a：20/30 + 列差 ≤ 航程 | 落位后按距离判激活态             |
| 盒 → 盒     | **不提供**                | —                                |
