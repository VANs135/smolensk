# 初设空军四栏 + 教学 PVE 改造（2026-11-19）

> 用户口径：① 初设不要用下拉选“进入地图外空军盒”；同型飞机按「激活/未激活 × 完好/减损」分四份，
> 点某一枚后在**该算子上方**出现「入盒」，点地图高亮格则落在图上；② 教学模式里苏联是人机对手，
> 空战教学轴心必胜，出击飞机要够炸出并应用“防御方受损”；③ 完成后推送 git。

---

## 1. 初设飞机：四栏 + 逐枚「入盒」

### 改前问题

- `DecisionQueue.vue` 的图外盒入口是 `<select>`「放入图外盒…」，只能按**机型**选，
  同型的激活/未激活、完好/减损四类混在一起。
- 飞机阵列只按激活态分两栏，减损仅用「减」角标；`SetupPanel` 每型只出一张“下一枚”卡，
  另外三种面根本点不到。
- store 的 `airStatusOrder` 只置换 `statuses`，没有同时置换 `reduced` / `steps`：
  在「激活」栏点一枚减损机时，会把“激活”贴到减损那枚的军力上（状态与印值错位）。
- 撤回快照没有记录这个顺序，撤回后状态/减损仍停在撤销前。

### 改后

| 项                                                              | 落点                                                                                      |
| --------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| 四栏固定顺序：激活·完好 → 激活·减损 → 未激活·完好 → 未激活·减损 | `DecisionQueue.vue#AIR_FACE_GROUPS`；`SetupPanel.vue` 用 `group-mode="sections"`          |
| 逐枚面的唯一投影（带计划下标）                                  | `stores/setup.ts#pendingAirFaces`                                                         |
| 置换**下标**（三条并列数组一起走）                              | `airFaceOrder` + `selectAirFace`；`placeAirRowNow` 按同一下标取 `statuses/reduced/steps`  |
| 点算子 ⇒ 地图高亮基地格；上方出现「入盒」                       | `pickAir` → `beginAirPlacement(..., status, reduced)`；`queue__air-send`                  |
| 「入盒」按**玩家点的那一枚**放                                  | `placeAirInOffMapBoxNow(side, entryIndex, faceIndex)`                                     |
| 没有基地格时仍可入盒                                            | `beginAirPlacement` 只在「无候选且不可入盒」时拒绝；选中后候选为空，UI 提示直接点「入盒」 |
| 撤回包含飞机面的顺序                                            | `capturePlacementState().airFace` / `undoLastPlacementNow` 还原                           |

`CounterPicker` 顺带扩了两个通用能力（不是初设专用）：

- `group-mode="sections"`：分组**平铺**成小标题，不再用下拉换组；
- `pick-action-label="入盒"` + `@action`：选中卡上方出现一个动作按钮，由调用方决定语义。

## 2. 教学模式：苏军改为 AI，空战轴心必胜

### 改前问题

- `ScenarioSetupView` 勾教学时写死 `hotseat.setMode('solo')`：苏军由玩家自己摆、自己打，
  不是人机对手。
- 轰炸只选 Ju.88 + Bf.110（轰炸值 12+5=17），且拦截空战/轰炸骰都随机：
  轴心可能输掉空战，轰炸也常常只出 DG、没有军力损失。
- 反应阶段的“苏军反击”由脚本代打；若改成 AI，脚本会和 AI 抢同一批动作。

### 改后

| 项       | 口径                                                                                             |
| -------- | ------------------------------------------------------------------------------------------------ |
| 对局模式 | 教学固定 **PVE + AI 打苏联**；玩家执轴心（`ScenarioSetupView` 两处入口）                         |
| 苏军初设 | 由 AI 的 `presetSelfSetupNow({onlySide:'soviet'})` 落位；玩家只布轴心                            |
| 出击编成 | 14.2a 四机：Ju.88 + Do.17z + 两架 Bf.110（轰炸值 12+8+5+5=30）                                   |
| 拦截空战 | 固定 2d6=6、损失骰 1：6 + I.153 ACV 1 − Bf.110 ACV 3 = 4 ≤ 6 ⇒ 拦截机返航，轴心胜（14.3e/14.5）  |
| 防空     | 固定 12 + 损失骰 1 ⇒ 不命中，四机完整进入轰炸（14.4e）                                           |
| 轰炸     | 固定骰面 11；30 点初始列 25-40 ⇒ 「1」＝ DG + 1 点军力损失（10.0a）                              |
| 受损应用 | 引导停在「确认受损单位」，由玩家把 1 点损失落到 19.27 的目标单位                                 |
| 反应阶段 | 苏军是 AI ⇒ 教学脚本**不再代打**（`if (aiSoviet.value) return`）；该步在阶段离开 reaction 时收束 |

固定骰面只走既有裁判入口（`airInputs.interceptDie/interceptLossDie/flakDie/lossDie`、
`barrageInputs.die`），不改任何引擎判定。
