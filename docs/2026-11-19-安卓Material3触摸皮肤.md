# 安卓 Material 3 触摸皮肤与 APK（2026-11-19）

> 用户口径：按 Android UI kit 重构 UI、适配触摸屏，并打包安卓版。
> **说明**：仓库与工作区里没有找到名为 Android UI kit 的设计文件；本批按 Android 官方
> **Material 3** 规范落地（48dp 命中区、底部导航、底部 sheet、FAB、安全区）。
> 若后续提供具体 kit（Figma / 组件库），颜色与组件尺寸可在此皮肤上逐项对齐。

---

## 1. 平台识别

| 项                        | 落点                                                                             |
| ------------------------- | -------------------------------------------------------------------------------- |
| 只在 Capacitor 安卓壳命中 | `src/shared/platform.ts` 把 `Capacitor.getPlatform()` 写到 `html[data-platform]` |
| 装配即挂属性              | `src/main.ts` 在 `createApp` 前调 `applyPlatformAttribute()`（首帧不闪桌面尺度） |
| 桌面 / 手机浏览器         | `web`，`android.css` 整段不命中，观感不变                                        |

## 2. Material 3 触摸皮肤（`src/styles/android.css`）

| 组件     | 改动                                                                        |
| -------- | --------------------------------------------------------------------------- |
| 命中区   | `--control-height: 48px`、`--control-height-sm: 40px`；算子阵列 ≥44dp       |
| 底部导航 | ≤1024px 转为底部五等分：24px 图标 + 12px 标签 + 选中药丸（`aria-expanded`） |
| 抽屉     | 转底部 sheet：28px 顶圆角、72% 最大高、顶部拖动指示条、上滑动画             |
| 初设队列 | 转底部 sheet（58% 最大高），**安卓壳内禁止拖动**（避免与地图平移抢手势）    |
| 地图工具 | 右下横条改为**右上 FAB 簇**（− / + / 全图），隐藏坐标/百分比/图例           |
| 安全区   | 根容器 `padding-top: var(--safe-top)`；导航/抽屉/队列让开 `--safe-bottom`   |
| 触摸反馈 | 按下 `scale(.97)`、去 tap highlight、统一 focus ring                        |
| 滚动     | sheet 内 `overscroll-behavior: contain`、隐藏滚动条、输入框 16px            |

模板侧只加了一个平台判定（`isAndroidPlatform()`）来禁用初设队列拖动；其余全是 CSS。

## 3. 顺带修掉的触摸端问题

1. **逐枚「入盒」动作条**：原来贴算子边缘的浮标会被底部 sheet 裁掉；改为四栏**正上方**一条
   横条（飞机名 + 面 + 「入盒」按钮），点完该枚进图外盒，计数 7→6 已实测。
2. **空面不占版面**：四栏里没有该面的飞机就不出空标题（7 架全未激活时只显示「未激活·完好 7」）。
3. **通用「地图外空军盒」按钮**在安卓上隐藏（拖动进盒时仍保留落点）；逐枚入盒已覆盖。
4. **教学卡**移到流程条下方、限宽 320px，右侧给 FAB 留 88px；不再盖住算子阵列/缩放按钮。
5. **地图首屏适配**：`MapCanvas#syncSize` 在用户尚未手动缩放前，容器二次撑开时重新
   `fitToWindow()`；修前会停在“挂载瞬间小视口”的坐标上，表现为地图偏下、上方一大块空白。

- 实测初设队列：7 枚飞机 → 点一枚 → 上方动作条 → 「入盒」→ 6 枚。

  **78 文件 / 504 用例全绿**。
- `npm run lint && npm run format:check && npm run typecheck && npm run arch` 全绿。
- `apksigner verify` 通过；`aapt dump badging` 包名/版本/SDK 正确。

## 6. 未覆盖

- 没有实体安卓设备 / 模拟器：触感、软键盘、系统返回键、刘海实测仍需上机。
- 未引入 `@capacitor/status-bar` / `@capacitor/app`：状态栏配色走 `theme-color` 与 WebView 背景，
  系统返回键仍是默认行为（退出应用）。如需原生返回键接管，另起一批加插件。
- 老 APK 的 hashed 资源仍留在 `assets/public`（覆盖式更新，未做镜像清理），故 23MB 略大于
  干净构建的 21.4MB；不影响运行。
