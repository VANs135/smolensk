# 安卓去白框 · 初设单排横向带 · 按钮精简（2026-11-19 回执）

> 需求原文：「把安卓版的这些白框UI都去掉，初设用单排排列，左右拖动展示，只留最简化的按钮」
> 三条经确认的口径：① 全部面板去白框；② 所有待落项铺成一条横向带；③ 主操作常驻、次要收起。

## 一、去白框 → 深色玻璃 HUD

- `src/styles/android.css` 定义一组 `--glass-*`（深半透明底 `rgb(24 27 26 / 0.86)` + 浅字 `#eef2ee`），
  只服务安卓壳、HUD 恒定深色 ⇒ 明暗主题下对比度一致、压在彩色地图上仍可读。
- 一组共享选择器（`.queue / .tut__card / .bar / .gt__rail / FAB / .gt__drawer / .queue__group /
.queue__active / .queue__air-pickbar`）就地重映射 `--color-ink/-muted/-rule/-panel/-bg/-teal-bg`
  为玻璃值：白底+边框消失，改深玻璃 + `backdrop-filter: blur(8px)` + 透明边框。
- 补 `--color-muted` 重映射修流程条小字（回合/日期/布设方）在深底上看不清的问题。
- 算子小卡（`.queue__cell/.queue__air-chip/.queue__counter`）边框/底改玻璃线 + 半透明。

## 二、初设待落项 → 单排横向带

- 安卓下 `.queue__sections` 由 grid 改 `display:flex; flex-direction:row; flex-wrap:nowrap;
overflow-x:auto; scroll-snap-type:x proximity`，四堆叠（地面/非战斗/飞机/卡车）横向并排、手指左右滑。
- 每个 `.queue__stack` 用 `flex:0 0 auto`，内部 `.queue__grid` / `.queue__air-array` 改单行 nowrap +
  `width:max-content`；飞机四栏横向并排成一行。
- 桌面 grid 布局不动（全部规则锁 `data-platform=android`）。

## 三、按钮精简 → 主操作常驻、次要收起

- `DecisionQueue.vue` 加 `androidUi = isAndroidPlatform()`（装配时一次确定）。
- 主操作常驻：开始游戏 / 完成初设（`setupPrimary`）、确认本方布设。
- 次要动作（一键预设初设 / 撤回上一步 / 预设结果提示）收进 `<details class="queue__more">`：
  - 安卓：summary 渲染成 40px 玻璃「⌄」图标按钮，默认收起，展开为悬浮小面板；
  - 桌面：`:open="!androidUi"` 恒展开 + summary CSS 隐藏（`display:contents`），观感与改前一致。
- 一份模板两平台共用，不重复代码。
