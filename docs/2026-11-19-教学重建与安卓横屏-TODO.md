## 任务二：安卓 UI 最简化 + 横屏紧凑档

### 现状

- `src/styles/android.css`（345 行）只有 `max-width:1024px` / `max-width:600px` 两套断点，**无 orientation 分支**。
- 横屏手机（如 915×412、1280×720）：宽 > 900 仍命中 1024 档，沿用竖屏的 48dp 命中区、
  底部导航高度、sheet 高度、教学卡尺寸 ⇒ 视觉过大、地盘被挤。

### 方案（已完成 ✅）

- [x] 无头 Edge 横屏截图核对现状（`D:/OCS/_tmp_review/android-landscape-probe.mjs`，916×412 + 1280×720）。
      **根因**：所有断点只看 `max-width:1024px`，1280 横屏完全不命中 ⇒ 退回桌面竖排导航 + 大面板；
      916 横屏命中但导航 71 / 流程条 83 太高，地图被挤到 201px。
- [x] 断点改为 `@media (max-width:1024px), (orientation: landscape)`：横屏无论多宽都走底部导航 + sheet。
      所有规则仍带 `html[data-platform='android']` 前缀，桌面 / 手机浏览器横屏不受影响。
- [x] 新增横屏紧凑档 `@media (orientation: landscape)`：导航 68→52px、FAB 52→44px、
      初设 sheet 限高 62%、教学卡限宽 260px 并隐藏介绍段、流程条收紧；竖屏专属的
      「教学卡下移 200px」加 `(orientation: portrait)` 限定，横屏不再中招。
- [x] 更新 `tests/render/android-touch-skin.test.ts` 守卫（横屏断点、52px 导航、44px FAB、
      隐藏介绍段、portrait 限定）。4 条全绿。
- [x] 实测截图：1280 横屏从「左侧竖排导航 + 桌面大面板」变为「底部五项导航 + 全宽地图 + 右上 FAB +
      底部 sheet」；916 横屏地图高 201→233、导航 71→52；教学卡不再压流程条信息。

### 验收（达成）

- 横屏截图无重叠/裁切/溢出；竖屏与桌面不受影响（选择器锁 android）；守卫测试与门禁全绿。
