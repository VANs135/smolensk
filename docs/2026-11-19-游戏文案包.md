# 游戏文案包 v6（背景导入 + 教学 + 术语 · 史实校准）

> 创作口径：**德译普鲁士军语腔**——靠德语语序与名词化立形，不靠文言虚词；**但拆掉中文四字格**，句式长短交错，不用「整理后勤」「逐段执行」「实施突袭」这类四字顿挫。
> 术语与阶段名（战斗补给、堆叠突袭、结算战斗、增援 SP）保留原词——那是界面既有词汇，不拆；描述句全部重写。
> 迭代：v1 白话 → v2 民国旧公文腔 → v3 教学转容克腔 → v4 背景导入改态势报告体 → v5 全面去四字格 → v6 按历史资料校准事实并订正三处编制与单位名 → v7 去掉人机感（命令句不再用电报式断裂句）→ v8 署名分层（参谋部呈报、霍特签发、第 39 装甲军受令）→ v9 把第三人称改成「我们」：当事人进场 → v10 通篇按同一条标准复查一遍 → **v11 术语卡与背景导入收尾，并补「多变体同步」自查项**。
> **同一稿的多个变体必须同步改**（v11）：主稿 / 速写体 / 命令体三处若不同步，就会漏掉旧句——历史上已发生过两次「主稿改了、变体没改」。
> **通篇复查标准**（v10）：所有文案块按同一条线过——史实有出处、人称锚定到「我们」（轴方）、无电报腔、无四字格、署名分层。本轮已按此标准重写背景导入三个变体、教学 19 步、结算卡、七条剧本提要。
> **人称必须锚定**（v9 新增）：文件里出现「我们」，指的是谁要当场讲清楚——参谋部呈报中的「我们」＝集群与所属部队（玩家就在其中），与末尾抄送的第 39 装甲军一致；不要出现无所指的第一人称。
> **署名必须分层**（v8 新增）：呈报者（集群参谋部）、签发人（霍特）、受令方（第 39 装甲军）三者不可混用——霍特不下命令给自己，他签发命令。
> **人机感禁区**（v7 新增）：不写宾语前置的断裂句（「维捷布斯克，拿下来。」），不写并列否定的电报堆叠（「不等到步兵，不等到补给车。」）。命令句写成一整句动宾——「不惜一切代价迅速夺取维捷布斯克。」——主谓宾齐全，状语带节奏。
> 所有史实细节已与 `scenarios.json` 起始态势核对；所有数字、地名、番号均来自剧本数据或公开战史，无虚构战果。
> **v6 起，正文只写有出处的事实**——逐句出处见第八节「史实依据」。
> **本文档是文稿的唯一载体**：本轮及后续文案只写在这里，`src/` 未作改动（教学文案的落码已撤回）。

## 一、背景导入（v6 · 史实校准）

**体裁**：第 3 装甲集群态势报告（德军原件体例 `Lage`）。只写事实与命令，无比喻、无感慨、不对玩家说话；句式长短交错，不落四字格。

**本版新增**：全部史实锚点换成有据可查的具体事件（迪斯纳、乌拉、别什科维奇、施密特将军的第 39 装甲军），并把剧本卡上的「7 月 8 日有限飞行」写进正文。逐句出处见第八节。

### 1.5 与盘面的咬合

- 玩家手上的第 20 摩托化步兵师，史实里正是**施密特将军第 39 装甲军**从别什科维奇派出的那个师；项目教学把 39 军 HQ 搬到 14.28，与史实的指挥关系对得上。
- 盘面上苏军的 14、18 坦克师属**第 7 机械化军**（第 20 集团军方向），背景导入写「第 7 机械化军的坦克师正往里赶」，指的是同一批部队。
- 剧本卡天气写的是 `Limited Flight on 8 July`，正文那句「今天的飞行有限，斯图卡给不了多少支援」是它的正文版；史实中 8 日的斯图卡正掩护渡河，两边对得上。
- 「我们面临补给短缺」正对剧本卡的挑战目标——**尽量少用 SP**。这句话既是态势，也是玩家在整局里要解的题。
- 命令链上有三层：参谋部呈报态势 → 霍特签发命令 → 抄送第 39 装甲军。玩家在第三层往下（施密特将军的第 39 军，辖第 20 摩托化步兵师），所以教学卡里霍特说话并不越级——他下的是集群命令，落到玩家手上已经过了一军之转。
- 历史上主力从城北迂回，剧本里玩家从西面推进——这是剧本设定，与史实不必一致，导入文字因此只说「直扑维捷布斯克」，不点方位。

### 1.6 文件的层级（谁写的、谁签的、玩家在哪一环）

| 角色                     | 在这份文件里的位置       | 对应项目                          |
| ------------------------ | ------------------------ | --------------------------------- |
| 第 3 装甲集群参谋部      | 态势报告的呈报者（附件） | ——                                |
| 霍特                     | 命令的签发人             | 教学卡里说话的那一位              |
| 第 39 装甲军，施密特将军 | 受令方（抄送）           | 玩家所属的军，即项目里的 39 军 HQ |

## 三、教学 19 步（全量替换稿 · 去四字格 · 史实校准）

改法：`title` 求「一瞥可懂」，`hint` 求「一道命令」，`intro` 求「为什么 / 这是什么」。所有 hint 均在 40 字内。

**去四字格的边界**：界面既有术语与阶段名照旧（战斗补给、堆叠突袭、结算战斗、呼叫轰炸、增援 SP）——那是界面上的词，动它只会让玩家对不上按钮；被拆的是**描述句**，把「整理后勤」「逐段执行」「实施突袭」「四机齐出」这类四字顿挫换成长短不一的自然句。

## 五、术语小卡（4 条，建议做成教学卡下方的折叠）

| 缩写     | 全称                          | 一句话                                                                                 |
| -------- | ----------------------------- | -------------------------------------------------------------------------------------- |
| SP       | 补给站（Supply Point）        | 补给站囤积我们的物资，包括油和弹药，战斗补给也从这里出。这是我们最后赶得上的一批补给。 |
| AR       | 行动值（Action Rating）       | 攻方宣布 AR 单位，战斗才算发起——挑我们这边最强的那个就行。                             |
| DG       | 编制被打乱（Disorganization） | 我们的部队被打散之后，机动和战力都要打折，要等补给阶段才能恢复。                       |
| Eq / Pax | 装备 / 人员补员               | Eq 补装备，Pax 补人。重建我们损失的单位，按表扣这两个点数。                            |

> 这四条只写「是什么 + 怎么用」，不写具体数值与表列，避免与规则原文冲突；数值一律留在 `?` 提示里。
> SP 一条按原拟句「补给站囤积我们的物资，包括油和弹药，这是能赶上我们最后的补给」改写：末句语序不顺（"能赶上……的补给"），理顺为「这是我们最后赶得上的一批补给」，其余用词照原句。
> DG 项目内没有统一中文译名（界面上一律用缩写 `DG`），故「全称」列写「编制被打乱（Disorganization）」，不另造译名。

## 七、可调整方向

- **判断一句话像不像人写的**：念出来。念着卡住的地方就是电报腔。「维捷布斯克，拿下来」念出来是顿号式的短促停顿，像机器在播报；「不惜一切代价迅速夺取维捷布斯克」念出来是一句完整的话。写完逐句念一遍，卡壳的句子改成一整句动宾。
- **写文案前先查史料**：v6 的教训是原稿有三处「听起来对、其实不准」的编制与单位名（30 乘汽车营被写成装甲侦察营、43 工兵营被暗示为师属、20 摩托化师编成被简化）。凡是能查到编制表与战史的句子，都要落到具体番号与地名，别用泛称。
- **四字格是这轮的主要禁区**：中文公文与军令天然爱四字顿挫（整理后勤、逐段执行、实施突袭、四机齐出），一用就显板正。v5 把描述句全部拆成长短不一的自然句，只保留界面术语与阶段名的四字形态。若还要更口语，可再拆一层（「全堆一起压上去」→「全堆都压上去」），但不宜再软——再软就不是军令了。
- **背景导入的三个变体**：主稿（态势报告全文）、变体 A（速写 150 字）、变体 B（命令开篇）。三者可共用同一份数据，只是排布不同——落码时按弹窗高度与安卓横屏可用宽度选一个即可。
- **腔调还有一档可上**：教学卡若 v3 仍嫌不够硬，可整体转**电报体**——去主语、全被动、省略系词，如「本堆燃料补给完毕。装甲可动。」`hint` 会压到 15 字内，代价是可操作性下降（玩家要点哪个按钮需要自己找）。
- 若嫌霍特口吻太密：可只保留第 1、3、9、13、17、19 步的「霍特：」，其余改纯指令（需同步把测试的「≥10 条含霍特」下调）。
- 若要做**中文军事术语统一**：建议 `Pax / Eq / Arm Rec` 在首次出现处补中文（补员点数 / 装备点 / 装甲侦察车），后续仍用缩写，免得卡面过长。
- 若要**史实加厚**：可在态势报告后再加一段德军单位级细节（如某营的行军序列、某桥的争夺），但同一体裁内不宜混散文。
