### 1.5 与旧稿的差别（为什么重写）

旧稿是**战地纪实散文**：比喻密（「门现在半开着」）、有对玩家说话（「你待会儿要打的，就是它们」）、修辞收尾（「没油坦克就是废铁」式的口语）。这些在正文里好看，但作为**导入**会提前泄底——玩家还没坐下，战役的紧张感已经被解释完了。

新稿改成**态势报告体**：

|            | 旧稿                         | 新稿                     |
| ---------- | ---------------------------- | ------------------------ |
| 体裁       | 纪实散文                     | 德军态势报告（`Lage`）   |
| 比喻       | 「门现在半开着」「情报错了」 | 无                       |
| 对玩家说话 | 「你待会儿要打的，就是它们」 | 无；判断交给「命令」句   |
| 结尾       | 「用完没有第二批」（口语）   | 「所余 SP 有限」（军语） |
| 落款       | 无                           | 命令签发人 / 集群番号    |

史实锚点全部保留并逐条核过：7 月 3–4 日强渡西德维纳河、7 月 8 日进抵城西、第 19 集团军卸载未毕且德军情报此前不知其存在、第 7 机械化军坦克师自西南开入、第 2 装甲集群于南面第聂伯河寻渡口。第 7 机械化军接的是盘面上的 14、18 坦克师——文案与地图咬合，不是各说各话。

**写作说明**

- 史实锚点：7 月 3 日两集群东调、3–4 日强夺德维纳河渡口、7 月 8 日已从城北迂回、第 19 集团军尚在卸车、德军情报未知其存在、7 月 10 日古德里安渡第聂伯河。剧本起始日正好落在这条线上，玩家接手的不是「假想开局」。
- 第 7 机械化军接的是盘面上的 14、18 坦克师（教学要打的目标），让文案与地图咬合，而不是各说各话。
- 末句「用完没有第二批」把剧本的挑战目标（尽量少用 SP）提前埋进去，不写成规则条目。
- 全篇不出现「英勇」「溃败」一类评价词：只给动作、位置、数量，让玩家自己判断局面。

### 腔调辨析：为什么 v2 像国民党公文

v2 用了「者……之谓」「非无偿」「无从谈起」「不得逾越」——这些是**中文训诂与旧公文**的虚词，落到军令上就是「着即」「仰即遵照」「特此训令」那一路。真正的德译普鲁士腔不靠文言虚词，靠的是**德语语序与名词化**直译出来的东西：

| 手段               | v2（错）                       | v3（对）                         |
| ------------------ | ------------------------------ | -------------------------------- |
| 名词化             | SP 者，油与弹药之谓            | SP 为油料与弹药之计量单位        |
| 被动状态句         | 补给不到，进攻无从谈起         | 补给未经确认，攻击不得实施       |
| 前置定语（德语式） | 将 19.27 予以摧毁              | 对 19.27 实施轰炸                |
| 编制表用数字       | 两个步兵团、装甲侦察营、炮兵团 | 步兵团二、装甲侦察营一、炮兵团一 |
| 落款签名           | ——                             | 命令签发人：霍特 / 第 3 装甲集群 |

保留：命令式、无人称、逐段下达、「不得」「予以」。去掉：文言虚词、成语式修辞。

### 改动要点（相对 v1）

- 去口语：「怎么摆」「别急着开火」「理顺」「撞上来」换成军语——察明布势、未接到命令不得开火、整理后勤、撞碎于阵地之前。
- 去国民党公文腔：「之谓」「非无偿」「无从谈起」「不得逾越」全部清除，改用德译官样文的「为……之计量单位」「未经……不得」「予以」。
- 单位一律称「敌军 / 敌 / 本堆 / 该 Arm Rec」，符合德式军语以番号与代号指称对象的习惯。
- 第 3 步保留「本日仅一回合」：这是**一天定胜负**的剧本，玩家必须先知道时间尺度。

## 五、术语小卡（4 条，建议做成教学卡下方的折叠）

| 缩写     | 全称                    | 一句话                                           |
| -------- | ----------------------- | ------------------------------------------------ |
| SP       | 补给点（Supply Point）  | 油、弹药、战斗补给都从它出。用完没有第二批。     |
| AR       | 行动值（Action Rating） | 攻方宣布 AR 单位，战斗才算发起。                 |
| DG       | 混乱（Disruption）      | 编制被打散，机动与战力打折，要等补给阶段才恢复。 |
| Eq / Pax | 装备 / 人员补员         | Eq 补装备，Pax 补人。重建损失单位按表扣。        |

> 这四条只写「是什么 + 怎么用」，不写具体数值与表列，避免与规则原文冲突；数值一律留在 `?` 提示里。

## 七、可调整方向

- **背景导入的三个变体**：主稿（态势报告全文）、变体 A（速写 150 字）、变体 B（命令开篇）。三者可共用同一份数据，只是排布不同——落码时按弹窗高度与安卓横屏可用宽度选一个即可。
- **腔调还有一档可上**：教学卡若 v3 仍嫌不够硬，可整体转**电报体**——去主语、全被动、省略系词，如「本堆燃料补给完毕。装甲可动。」`hint` 会压到 15 字内，代价是可操作性下降（玩家要点哪个按钮需要自己找）。
- 若嫌霍特口吻太密：可只保留第 1、3、9、13、17、19 步的「霍特：」，其余改纯指令（需同步把测试的「≥10 条含霍特」下调）。
- 若要做**中文军事术语统一**：建议 `Pax / Eq / Arm Rec` 在首次出现处补中文（补员点数 / 装备点 / 装甲侦察车），后续仍用缩写，免得卡面过长。
- 若要**史实加厚**：可在态势报告后再加一段德军单位级细节（如某营的行军序列、某桥的争夺），但同一体裁内不宜混散文。
