## 4 接自己的模型

服务端单独启动：

```bash
npm run train:stdio -- --scenario=1 --seed=20261126
```

stdout 只走逐行 JSON，诊断写 stderr；训练侧按行解析，不要读日志文本。

启动握手：

```json
{
  "type": "hello",
  "protocol": "ocs-train-stdio/1",
  "trainVersion": 3,
  "commit": "<server HEAD 短哈希>",
  "pid": 1234,
  "defaults": { "scenarioId": "1", "seed": 20261126 }
}
```

训练侧第一件事：校验 `trainVersion === 3`，不匹配就退出，不要加载旧 v2 数据或权重。

命令面：

| 命令                     | 用途                                                                                           |
| ------------------------ | ---------------------------------------------------------------------------------------------- |
| `reset`                  | 开一局；`scenarioId`、`seed` 必填，可带 `control`、`maxSteps`、`maxNoopSteps`、`maxSetupSteps` |
| `observe`                | 只取当前观测/候选，不推进                                                                      |
| `candidates`             | 只取候选                                                                                       |
| `step`                   | 传上一条候选的 `key`，或直接传 `action`，或 `policy:"scripted"`                                |
| `checkpoint` / `restore` | 局面快照 / 回滚                                                                                |
| `actionKey`              | 把 `action` 转 canonical key                                                                   |
| `snapshot`               | 原始 `AiSnapshot`，仅诊断                                                                      |
| `close`                  | 关闭进程                                                                                       |

`step` 响应含 `observation`、`candidates`、`actionKey`、`reward`、`done`、`terminal`、`info`。`info` 里要区分：

- `ok=false` + `rule`：规则拒绝，是负样本/违规，不是通信失败；
- `fellBack=true`：模型输出结构非法或抛异常，回退脚本策略，不能当专家动作；
- `noop=true` / `stalled`：空转，连续空转会被截断；
- `truncated=true`：达到 `maxSteps`，不是会话终止。

错误统一：

```json
{ "id": 1, "type": "error", "ok": false, "error": { "code": "unknown_key", "message": "..." } }
```

`key` 不在当前候选里会得到 `unknown_key`。候选表 v1 不声称穷举；有自定义动作就直接传 `action`。

## 7 已知边界 / 待拍板

1. **旧 v2 数据不自动兼容**：`AI_TRAIN_VERSION=3` 后，旧 JSONL/权重默认拒载；要么重采，要么显式转换并记录转换口径。
2. **`terminal.winner/outcome` 的来源**：只取会话终止后的操作台/评估侧推入判定；训练环境不重算。未终止或部分终止路径可能为 `null`，训练侧不要把它当唯一奖励源。
3. **无单步超时**：服务端不设 `decide-timeout`；训练侧自己控制策略超时、重启与作废该局。
4. **协议只搬运**：奖励、终止条件、模型结构、课程学习由训练侧定义；本仓只保证观测/候选/动作/状态回传一致。
5. **候选表 v1 非穷举**：训练侧可以走 `action` 直传；若要补候选投影，另开任务，不在本轮改引擎规则。
6. **模型尚未接入**：Python 样例只验证协议与脚本/候选路径；真实模型推理、训练循环、权重回灌未开始。

## 8 回报模板

朋友侧出问题时，按这几项发回来即可定位，不用贴整段日志：

```text
commit: <git rev-parse --short HEAD>
protocol: ocs-train-stdio/1
trainVersion: <hello 里的值>
scenario / seed / control / maxSteps:
命令: <reset/step/...>
请求 JSON: <一行>
响应 JSON 或错误: <一行>
stderr 尾部: <最后 20 行>
是否可复现: 同 seed 再跑一次
```

若他原有训练代码对消息形状有固定假设，把他实际发送/期望的 JSON 贴回来；引擎侧按他的客户端适配，不改规则与训练数据口径。
