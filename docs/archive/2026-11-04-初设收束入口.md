# S1首批：初设收束与开局入口

本批按新计划从S1初设链开始，处理剧本1真实自动初设和德军抽取之后的收束。没有继续空运功能，也没有修改苏军动员或增援日程。

## 问题与改动

1. 初设已结束后重复调用“开始游戏”，旧代码仍执行会话推进，可能越过第一个玩家环节。现在已完成初设且会话存在时直接保持当前对局；该入口不再充当阶段推进按钮。
2. 未给出的必做编队西移落点，旧代码会标为完成并留在原格。新增纯规则校验，收束和开局都先检查待完成西移；缺失时保留任务、盘面及抽签结果，提示完成放置后重试，不先创建会话。
3. 开局失败时，旧代码会先清除正在点地图放置的初设项。现在只有成功收束才清除，失败后仍可继续操作。
4. 重复收束保持幂等，不重复写入移除备注。普通未摆单位仍按用户此前“可主动不摆并视为本局移除”的口径处理，不将它与已有编队的必做西移混用。

`engine/rules/setup.ts`生成必做放置的校验结果；`stores/setup.ts`控制提交顺序和当前初设操作。沿用现有初设存档格式，没有新增持久字段。

## 验证与边界

新增5项真实store用例：重复开始、失败保留当前落位、直接收束和开始游戏两种入口的必做西移阻断/补齐、普通放弃与重复收束。剧本1自动西移按已有“视为有道路”裁定继续正常执行；缺失落位信息的用例显式构造待办，证明入口不能静默跳过。
