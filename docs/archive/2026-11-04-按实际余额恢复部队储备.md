# A3第十二批：按实际余额恢复部队储备

基线`a517270`。总计划以可达站并集计价，实际付款则按每个单位自己的可达站。因此总计划可完全恢复某耗尽单位时，实际来源仍可能只足够部分恢复。此前付款失败分支消费余额后不改单位状态，且完成日志仍报告原计划消耗。

本批在逐单位付款不足时，复用`planInternalStocksRecovery`按当前可达余额重新计算，支出上限不超过原分配给该单位的费用，避免抢占其它计划额度。部分恢复付款成功才落实ready/low状态，并计入特殊供养标记；付款失败则不改状态。恢复及浪费支出均只累计成功扣款，日志显示实际金额和实际状态，重复提交仍保持幂等。

新增2项独立域回归：原计划8T、实际剩2T时，一枚耗尽单位恢复为Low、另一枚保持耗尽，实扣2T；付款端口拒绝时单位和8T补给均不变、日志实扣0T。前一项同时核对重复提交不再收费。相关2个文件11项回归通过。

用例通过端口模拟计划后余额变化及付款失败，没有声称完成真实多来源网络的整体分配、完整供养/损耗流程或人工界面验收。整体来源分配和完整资源总账仍待验收，S1/R0未完成。存档格式未变；两份原有未跟踪UI分析文档未修改、未纳入提交。
