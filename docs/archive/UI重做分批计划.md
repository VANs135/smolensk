# UI 重做 · 分批实施计划（以减少缺陷为目标）

> 依据：`docs/UI重做方案.md`（用户 11 条裁定）与 `docs/备忘录处理台账.md`。
> 本文只管**怎么分批做**：每批的边界、顺序、验收与回滚。
> **总原则：每批小到"出错能一眼看出来、回滚只退一步"。** 分批不是为了快，是为了**错得可定位**。

---

## 0. 减少缺陷的十条机制（每条都对应一类常见事故）

| #   | 机制                                                                          | 防的事故                                        |
| --- | ----------------------------------------------------------------------------- | ----------------------------------------------- |
| 1   | **同批只做一类改动**：渲染 / 数据 / 接线 / 删除，各自成批                     | "改了三处，不知道是哪处坏的"                    |
| 2   | **先加后删**：新路径先与旧路径并存，验收后**单独一批**删旧                    | 新路径有 bug 时**无路可退**                     |
| 3   | **纯函数先行**：布局/命中/可点性/环节链都先写纯函数 + 单测，再接线            | 交互 bug 只能靠手点发现                         |
| 4   | **视觉改动写"绘制序断言"**：用假 ctx 记录 `drawImage/stroke` 调用序，断言层次 | 层次错了肉眼一时看不出（工事被算子压住）        |
| 5   | **每批结束跑「可玩通 Smoke 清单」**（§3，10 项约 5 分钟）                     | 改动跨面互相打伤，只跑单测发现不了              |
| 6   | **既有 2774 用例必须全绿**：要改测试必须在本批**单独说明理由**                | 用"改测试"掩盖行为破坏                          |
| 7   | **数据/引擎不与 UI 混批**                                                     | 数据 bug 与界面 bug 互相掩盖                    |
| 8   | **每批一个回滚点**：开工前备份 `src/`，收尾写回执（§4）                       | 无版本控制（本项目非 git 仓库）⇒ 备份是唯一退路 |
| 9   | **禁止跨批重构**：重构单独开批，且不与功能同批                                | 大 diff 无法 review                             |
| 10  | **不新增性能触发点**：不给全场追溯重判（单次数十秒）加新入口                  | 界面卡死（已实测过一次）                        |

## 2. 每批的**固定动作**（缺一步就算没做完）

1. **开工前**：`node scripts/…`（如需）→ 备份 `src/` 到 `backup/<日期>-<批名>/`（本项目非 git 仓库，备份=回滚点）；
2. **写代码**：同批只碰该批声明的文件；不顺手改别的（顺手改=第 1 条机制失效）；
3. **测试**：该批行为**先写测试**（纯函数批直接写；接线批至少一条流程用例）；
4. **门禁**：`npm run check`（lint → format:check → typecheck → test → arch）全绿 + `npm run build`；
5. **Smoke**：跑 §3 的 10 项手工清单（对照"修前也能过"的项，确认没退步）；
6. **收尾**：临时脚本移入 `backup/<日期>-<批名>/audit-scripts/`；`docs/待改清单与修改方案.md` 追加一节回执（含：改了什么、怎么验的、**还剩什么**、**回滚点在哪**）。

## 3. 「可玩通 Smoke 清单」（每批收尾照跑，约 5 分钟）

| #   | 动作                           | 期望                                             |
| --- | ------------------------------ | ------------------------------------------------ |
| 1   | 打开应用 → 开始台 → 进入对局台 | 有盘面（自动初设生效）、无报错                   |
| 2   | 流程条点「进入下一环节」       | 停在需要玩家的环节；自动段在日志里连续出现       |
| 3   | 点一个堆叠                     | **就地展开**、默认全选；点一枚能取消；再点格收起 |
| 4   | 移动一个单位                   | 高亮范围正确、落脚后 MP 扣减、已动状态可见       |
| 5   | 发起一次战斗并走完九步         | 只出现**一个**会话框；结束后地图恢复、选择集清空 |
| 6   | 发起一次炮击                   | 同上；苏联炮兵须同格、德国不受限                 |
| 7   | 执行一次空中任务               | 只列**本环节合格**的飞机；航程/短板可见          |
| 8   | 做一次补给（拖取或吃图上）     | 付款来源可见可点；账本扣减正确                   |
| 9   | 折叠/展开底部托盘（盒与表格）  | 两段各自可折叠；地图不被挤没                     |
| 10  | 存档 → 刷新 → 读档             | 状态完整恢复（含选择集/会话框状态）              |

> 新增功能后，往清单里**追加**对应项（清单只增不减，除 B17 删旧路径时可清理）。

## 5. 风险台账（每批开工前扫一眼本表）

| 风险                                         | 出现批      | 对策                                                                                                       |
| -------------------------------------------- | ----------- | ---------------------------------------------------------------------------------------------------------- |
| Canvas 与 DOM 命中穿透（点会话框穿透到地图） | B3–B4、B15  | 地图只监听自己的 `pointer`；DOM 浮层 `pointer-events: auto`；`hitTestHex` 先判浮层；**每批 Smoke 第 5 项** |
| 追溯重判性能（单次数十秒）                   | B8、B15     | 不给它新增触发点；如必须新增，先落覆盖集缓存（P1-1）再接线                                                 |
| 改动打伤既有 store 用例（约 300 条）         | B5、B8、B15 | 只动视图层优先；必须动 store 时**先补用例再改**；本批内单独说明                                            |
| 双入口腐化（对局台 / 操作台）                | B9 之后     | 交互组件只暴露 props/emits；B17 统一降级 `WorkbenchView`                                                   |
| 「先加后删」忘了删（旧路径腐烂）             | B17         | B17 是**纯删除批**，用 arch-scan 的零调用清单核对删净                                                      |
| 断言被"改测试"掩盖                           | 全部        | 机制 6：改测试必须在本批回执里写明理由                                                                     |
| prettier 对 Markdown/长表格                  | 全部        | 收尾先 `npx prettier --write` 再跑门禁                                                                     |
| 编码事故（改源码用 PowerShell 曾毁过一次）   | 全部        | 只用编辑工具或 Node 脚本（显式 `'utf8'`）；批量改后必验 U+FFFD 与 SFC 解析                                 |
