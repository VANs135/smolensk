# 左键堆叠窗极简 + 五项能力进右键（2026-11-09）

## 1. 口径（用户原话）

1. 左键点格子后的会话窗**只展示堆叠中的战斗单位**，默认**全部选中**；点某个算子即取消该单位
   选中、再点恢复。窗内**去掉说明文字**，只留算子与操作按钮。
2. 以下能力进**右键菜单**：转换延补队、拆分单位、合并单位、补员单位补员、加油。
   点单位/点格即出现可用项，**不满足就不出现、不灰按钮**；判据复用既有 store/engine 入口，
   不新写规则；规则号只进悬停或 `?`。
3. 右键继续承接低空扫射、装卸这类既有项，不搬动。

（用户先写「左键」后更正为「右键」，按更正后的执行。）

## 2. 第 1 批：左键窗只摆战斗单位、默认全选、点枚切换

- store（`map-view.ts`）：新增**纯界面**选中集 `stackPickIds`。
  - `openPopup(hex, x, y, 'content')` 时重置为该格**可见战斗单位**（`air !== true` 且
    `noncombatKind` 无值）的 id 全集 ⇒ 默认全选。
  - `toggleStackPick(id)` 取反；换格重开按新格重置。
  - 不落引擎：引擎侧取子仍是 `workbench.movePick`（6.1），本选中集只管窗内选中态。
- 组件（`MapActionPopover.vue`）：
  - 删去非战斗栏（SP / 运输点 / 基地 / 机场飞机的「展开/驻机/选入任务」）；这些入口留在
    右键能力菜单（基地的空袭入口仍在右键的「空军」组）。
  - 战斗算子改成可点选的 chip：默认选中，点一枚压暗（`chip--off`），再点恢复；
    `aria-pressed` / `Enter` / `Space` 同步。
  - 去掉堆叠标题、栏名、算子计数、被滤单位交代行、「点本方算子＝…」等说明文字；
    移动中/突袭/取子/整备/发起战斗几处的说明段落压成一行数字或删除。
  - 规则号从标题与按钮文案里移出：标题改为 `?`（`title="规则 x.x"`），
    按钮上的「（6.1）」「（15.1）」「（14.2f-A/B）」「（9.1）」移入 `title`。
- `MapPopover.vue`：`rule` 标签改为 `?`，规则号只在悬停提示里出现。

红测：`tests/stores/popup-stack-selection.test.ts`（3 例）——默认全选且不含非战斗；
点枚取消/恢复；换格重置。先红（`toggleStackPick` 不存在、`stackPickIds` 为 undefined）
后绿。
