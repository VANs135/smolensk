# 三操作统一流程：低空扫射 / 轰炸 / 炮击（规格，待批）

> 用户 2026-11-10 口径：一条骨架同时服务三种操作，**各步一个窗**，不把两件事塞一个窗；
> 先出规格再实现。实现排在：右键体系 → 8.1 两条偏离 → 轮式 EZOC → 空军盒精简 → 悬停浮现 之后。
> 本文只定流程与判据，不改代码。判据一律挂既有引擎入口；缺原文的进第 8 节待裁定。

---

## 0. 一句话

**右键敌方单位/堆叠 → 选操作 → 选参战单位（空军按基地分组）→（炮击吃补给 / 空军过空战·防空）→ 结算 → 确认战果收束。**
每一步一个窗，窗口内只放算子与按钮，条款号收进 `?`；每步都能后退/取消回到可继续的状态。

三操作共用同一骨架，差异只在**判据**与**第 3 步的内容**：

| 操作         | 环节（10.0 第二段 / 14.2e） | 候选来源                               | 第 3 步                    | 补给         |
| ------------ | --------------------------- | -------------------------------------- | -------------------------- | ------------ |
| 炮击（火炮） | 轰炸环节                    | 射程覆盖目标格的火炮                   | 吃补给（复用进攻补给那套） | 10.1b 要 SP  |
| 轰炸（空军） | 轰炸环节                    | 各基地可出动、航程够的轰炸机           | 空战/拦截/防空 → 结算      | 10.2c 免补给 |
| 低空扫射     | **移动环节**（14.7d/10.0）  | 各基地可出动、有扫射能力、航程够的飞机 | 空战/拦截/防空 → 结算      | 14.7a 免补给 |

> 原文依据：10.0 第二段（移动环节只放行低空扫射的空军）；14.7a「空军轰炸本身**从不**需要任何补给消耗」；
> 14.7d「结算方法与普通轰炸（14.7）相同，但有一些例外和限制」；10.1b「进行**一次火炮轰炸**时需要消耗战斗补给」。
> ⇒ 第 3 步的「吃补给」只对**炮击**开；空军两操作不出现该窗（不是置灰，是不出现）。

## 1. 骨架：四步、四窗

### 第 0 步｜入口（无独立窗，右键菜单）

- 触发：在可实行的环节，**右键敌方单位 / 敌方堆叠**（含设施目标格）。
- 菜单项按环节与判据过滤，**不出现不该出现的项，不做灰项**：
  - 炮击：轰炸环节 + 目标格在至少一门己方火炮射程内 + 10.0d 目标预先指定 + 10.1b 能付得起（付不起则整项不出现？见 8-①）；
  - 轰炸：轰炸环节 + 至少一架可出动轰炸机航程够 + 10.0e 该格本阶段未炸过；
  - 低空扫射：移动环节 + 至少一架有扫射能力（14.7d-B/专规 2.2a、3.2a）+ 10.0b 正确观察员 + 航程够。
- 数据来源：`map-view.ts` 的 `openUnitContext` / `enemyCounterAt` / `hipShootEntryEligible`；
  `barrageEligibility`（`src/engine/rules/barrage.ts:701`）；`assignAirMission`（`air-interaction.ts:511`）。
- 现有「空军任务（低空扫射 / 轰炸等，14.2e）」（`map-view.ts:1354`）与「低空扫射（14.7d）」（`:1510`）是**两个分散入口**，
  统一后合并为同一菜单的三个操作项（见第 6 节）。

### 第 1 步｜选参战单位（一个窗）

- **只列真正能参与者**（硬要求，见第 3 节）；炮击列火炮、空军列飞机；不混排。
- 空军**按所在基地分组**（含地图外空军盒，单独一组），组内默认不选；一组不选则该基地不参与（见第 4 节）。
- 选完 → 「下一步」；「取消」回到地图可继续态。
- 数据来源：`barrageEligibility` 的候选筛选；`assignAirMission` / `checkAircraftOrigin` / `airBaseAt` / `activeAircraftInBase`。

### 第 2 步｜补给（仅炮击）/ 空战·防空（仅空军）

**炮击（一个窗）**：复用进攻补给那套支付入口（同指挥部或同补给站；10.1b-A），显示应付 T 数与可用来源；
付不起时按 10.1b「**不能执行此次轰炸**（没有惩罚：所有单位取消轰炸，也不视为已轰炸过）」→ 本窗给出「取消本次」并回到可继续态。
数据来源：`canPayBarrageCost`（`barrage.ts:346`）、既有进攻补给支付（`supplySources` / `paySupply` 同一套）。

**空军（一个窗）**：多开「空战拦截 / 防空」窗，顺序照 14.2f：
C) 任务格双方都有激活飞机 ⇒ 空战（14.3）；D) 拦截（14.5）；E) 防空（14.4）。

- 有拦截：先结算空战（拦截按空战结算，14.5），没有拦截就只结算防空；
- 14.4a：受防空影响的任务（轰炸/低空扫射 always；空运/空投/基地转移 onlyInPatrolZone）由引擎判；
- 14.5：不强制拦截，每任务只能被拦截一次；
- 窗口内只放**参战机与按钮**（选机/返航/掷骰/继续），过程文字进日志。
  数据来源：`airCombatOccursAt`、`planInterceptionResponse`、`resolveInterception`、`resolveFlakStep`、`beginAirInteraction`（`air-interaction.ts`）。

### 第 3 步｜结算与收束（一个窗）

- 显示战果：按 10.0a/10.0c/10.0d 的表结果（军力损失、DG、设施命中），空军含 14.7c 短程横移与 14.7d-A 的「不占每格一次」例外。
- 玩家确认战果 → 写日志 → 收束；空军随后按 14.1c/14.7b 返航并转非激活（返航落点判据沿用既有）。
- 「上一步」可回到第 1/2 步（未落账前）；「取消」整单作废（炮击按 10.1b 不算已炸）。
- 数据来源：`resolveBarrage` / `resolveBarrageOutcome` / `resolveFacilityOutcome`、`confirmMissionStep`、`completeAirReturnStep`。

## 3. 候选口径（硬要求，同时是此前「炮击列出全部炮兵」的定案）

**只列真正能参与的单位，不列「己方所有」。**

- 炮击：只列**射程覆盖目标格**的炮兵，并同时满足弹药/补给/环节/模式等既有判据；打不到的一律不出现（不摆灰项）。
- 空军：只列**可出动的**飞机，且按基地分组；不在基地、已出任务、航程不够的不出现。
- 低空扫射/轰炸：同样只列能对目标格执行的那批（14.7d-B 单机、10.0b 观察员、10.0e 未炸过）。
- **集合等式（断言口径）**：给定目标格与若干炮兵/飞机，窗口候选集合 **恰等于**「射程/航程可达且当前可执行」的子集——
  多一个、少一个都算失败。
- **两处同源**：右键入口的「该项是否出现」与窗内候选必须来自**同一个**筛选函数（不得各算一套），
  断言要同时覆盖右键入口与窗口，避免两处判据不一致。

## 4. 空军候选按基地分组（补充口径）

- **分组对象**：每个图上空军基地算一组；**地图外空军盒也算一个基地**，单独成一组。
- **取机范围**：该基地/盒内、非激活、未出任务、航程够（14.2d）、任务类型允许（14.2e）的飞机。
  不从基地/盒里取机的不出现；已在空中或已出任务的飞机不出现。
- **默认不选**：组内默认不勾选，玩家点选本组要出动的飞机；一组不选则该基地不参与本次任务。
- **合计上限**：跨基地合计 ≤ 4 架（14.2f）。
- **呈现一致**：图上基地与图外盒用同一种呈现，只标明来源是哪个基地/盒；不额外加说明段落。
- **图外盒如何以「基地为对象」参与**：沿用既有「盒内等效入口」口径（盒在界面与判据上等同基地对象）。
  原文 2.1C 只说「地图外储存区域内不允许进行战斗」，**未明示**能否从盒出击 ⇒ 见 8-③。

## 7. 交互与窗口纪律

1. 一步一窗；窗口内**只放算子与按钮**，不放说明文字；条款号收进 `?`（`RuleTip`）。
2. 每步都有「上一步 / 取消」，取消后回到可继续态（不卡死）；炮击取消不算已炸（10.0e / 10.1b）。
3. 失败必须**可见**：判据不过时给一行原因（条款号在 `?` 里），不静默、不无响应。
4. 不新增规则：一切判据取既有引擎入口；引擎没有的，登记待裁定（第 8 节），不自行补。

## 9. 验收（整批）

1. 右键敌方单位/堆叠：三项按判据出现，不出现灰项；三项各自能走完四步并收束。
2. 候选集合等式（第 3 节）在**右键入口**与**窗内**同时成立（同一筛选函数）。
3. 空军候选按基地分组（图上基地 + 图外盒），默认全不选，合计 ≤ 4 架（14.2f）。
4. 炮击第 2 步扣账正确；付不起只给取消且不算已炸。
5. 空军第 2 步：有拦截先空战、无拦截只防空；不拦截合法。
6. 每步可后退/取消，取消后可继续做别的事；无静默失败。
7. 第 6 节列出的重复入口已删，同一功能只剩一条路径。
