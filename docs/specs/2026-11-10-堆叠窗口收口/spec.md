# 堆叠窗口收口（2026-11-10）

## 0. 本轮回改：显示规则定死（用户同日第二批）

在批 A（列全 / 默认全选 / 自动摊开 / 删说明）之上，用户把显示规则定死为四条：

1. **格内常态摊开**：任何格子的多枚单位/设施**不点也已经错位展开**（多了缩小、仍数得出枚数）；
   这是默认状态，不是「点了才摊」。仅敌方受 4.9a 战雾限制（隐藏或单枚显示）。
   实现：`token-layer` 对 `fan.length >= 2` 的格恒用 `stackFanLayout`，`expandedStack` 只承载
   「这一格翻到第几页」；`MapCanvas` / `map-view` 的四处命中与绘制同源。
2. **点格 → 堆叠展示窗口**：点格内**空白**弹列表窗口（整格全选 + 开窗），窗口不再承担「摊开地图」。
3. **单点某一枚**：命中落到具体算子，选中就是这一枚（不是整格）；右键菜单按这一枚的能力出
   （与窗内右键同一套 `openUnitContext`），命中不到某一枚才退回整格菜单。
4. **13.2g 编内卡车**：
   - 原文「编内卡车与**其他运输点数基本一样**，但有几 点例外」⇒ 按**特殊运输点数**建模：
     复用运输点数的能力（MA / 装载 / 可单独开拔 / 可单点选中），不为它另写运输逻辑；
   - 原文的例外只有 A–G（不能在地图上卸载 SP、只允许同一多单位编队拖取、不能合并为延补队、
     可进预备模式、可随撤退堆叠一起撤退但不可单独撤退、被夺取转为常规运输点数、
     可保留 SP 不付战斗补给）；
   - 它是**独立算子**（可单点选中、可单独移动，也能与所属编队一起选、一起走）；
   - **不阻断**：随行/单独走完后都不出现在「未动完」清单，不阻止其它单位开拔（13.2a 只对
     运输点数「暂停」的既有口径不扩到它）；
   - 窗口与地图都按运输点数算子呈现，窗口 chip 追加「随 <编队>」标注（不是说明段落）。

对应断言（`tests/stores/*`、`tests/render/*`）：

- 多枚堆叠格不点击已展开，枚数可数（`stack-fan-render` / `token-layer` / `draw-order`）；
- 点格出窗口且窗口含编内卡车（`popup-stack-selection`）；
- 单点地图某枚 ⇒ 选中的是这一枚，不是整格（`map-view-flow`）；
- 编内卡车可单点选中并单独开拔；与编队同选时一起走；两条路径都不产生「卡车没动完」提示
  且下一枚可立即开拔（`organic-truck-move`）；
- 取油路径三按独立算子口径回归（`fuel-three-paths-flow`）。

## 1. 批 A 口径（仍有效）

用户口径（按给定顺序，不跳）：

1. **列全**：左键堆叠窗列出该格**全部可见令牌**，不再按「本环节参与」或「战斗单位」筛选；
2. **默认全选**：摊开/开窗时，该格**本方全部可开拔算子**默认选中（地图扇面金环与窗内 chip 同一份
   `workbench.movePick`），点一枚取消、再点恢复；
3. **地图同格自动展开**：点己方堆叠即在地图该格自动摊开扇面，看得见是几枚；
   关窗 / 取消 / 切格即自动收起。**不做「地图展开 / 收起展开」按钮**（多一个按钮就多一步操作）；
4. **删说明文字**：窗内只留算子、状态与操作按钮，删掉规则解释段落。

## 2. 落地

### 2.1 store（`src/stores/map-view.ts`）

`expandStackAt(hex)`：

- 传给 `beginMovePick` 的候选集改为**该格本方地面令牌**（排除飞机、本阶段已结束移动者）；
  池过滤仍由 `movePickPoolAt` 负责，敌方 / 补员不会进入 `movePick`；编内卡车按 13.2g
  作为**独立运输点数**进入池（可单点、可单独开拔，也可与编队同选一起走）；
- `stackSelection = defaultSelectionOf(workbench.movePick?.ids ?? [])` ⇒ 恢复**默认全选**；
- 该格没有本方算子时 `movePick = null`，`stackSelection = []`（没有可选对象）。

### 2.2 组件（`src/components/game/MapActionPopover.vue`）

- 删除 `visibleGroundUnits` / `combatUnits` 两层过滤，改为 `stackUnits = popupContent.units`；
  同格飞机用 `popupContent.airUnits` 单列（只读）。
- chip 可点选的条件收窄为「本窗就是取子格（6.1）且该枚在 `movePickChoices` 里」；
  其余 chip 照列、不可点、不显示选中态。
- 删除「地图展开 / 收起展开」按钮及其 `popupHex` / `expandedHere` / `toggleExpandHere`；
  展开由 `onHexClick` 点己方堆叠时自动调用 `expandStackAt`，收起由 `collapseStack`（取消）、
  `onHexClick` 切格分支与 `closePopup`（关内容窗）负责。
- 删掉窗内规则解释段落（9.14 的静态说明、整备的容量/费用说明与「本格没有非激活飞机」），
  保留状态回执与操作按钮。

### 2.3 右键体系

- 地图右键敌方堆叠：`enemyCounterAt` + `hipShootEntryEligible` ⇒ 菜单出「低空扫射（14.7d）」，
  多枚目标合并为一份共用菜单；
- 窗内右键该单位：`openUnitContext` 只针对这一枚出菜单；
- `App.vue` 挂 `window` 级 `contextmenu` 监听，命中 `HTMLImageElement` 时 `preventDefault`，
  拦掉 WebView 原生「将图像另存为」；算子 chip 以 `@contextmenu.prevent.stop` 走自己的菜单。
