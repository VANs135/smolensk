## 二、`UI重做.txt`（整套交互规格）

**核心要求**（原文要点）：回合流程条置于地图窗口上方（阶段框含环节，到哪个环节就亮哪个；**轴心蓝 / 苏联红**）；
地图右侧最上为剧本选择，选完点开始 → 固定初设与「少数几格内自由初设」按范围中心自动落位 →
需玩家抉择的进**地图窗口左上角的框**（地面 / 非战斗 / 飞机 / 卡车各一堆叠，点开可多选）→ 选中单位时**高亮可放格** →
玩家按剧本轮流初设，共识开关**默认全不使用**；右侧菜单除剧本选择外**只做信息展示**（骰点、战果等）；
**一切战斗/轰炸/空中任务/补给都在事件发生时于地图上生成会话框**，事件结束即关闭，直到下一个事件；
可交互内容尽量在地图上直接渲染（点堆叠拾起可进攻单位 → 渲染可共同攻击的目标 → 点目标格进战斗会话；
炮击同法，注意**苏联炮兵联合炮击须同格、德国无此限制**；空军点基地格 → 展开飞机 → 多选编队 → 渲染航程短板 → 点航程内目标进任务会话，对方可选拦截）。
