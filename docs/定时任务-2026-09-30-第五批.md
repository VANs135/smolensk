# 定时任务建表说明（2026-09-30 起：第五批 review → 逐批修改）

> 为什么要这个文件：**能干的会话不能建任务** —— 如果当前会话本身就是由定时任务拉起的，系统会拒绝再建
> （原文："Cannot create a scheduled task inside a session that already belongs to a scheduled task"）。
> 请在**新会话**里建一次；本文件就是那段可以直接照搬的 prompt（避免手打长文）。

## 建表参数（照抄）

| 字段      | 值                                                                  |
| --------- | ------------------------------------------------------------------- |
| cron      | `0,30 * * * *`（每半小时、整点与半点）                              |
| recurring | `false`                                                             |
| maxRuns   | `14`（01:30 → 08:00 恰好 14 次：01:30 / 02:00 / … / 07:30 / 08:00） |

**title**（可整段复制）：
`2026-09-30 01:30–08:00 每半小时执行一次：先做第五批 review 并产出 docs/第五批修改方案.md，其后按该方案逐批（每轮一个切片、走六步固定动作）推进`

> 想换时段就改两处：cron 的分钟/小时字段与 maxRuns。次数 = (结束时刻 − 开始时刻) ÷ 30 + 1
> （例：23:00–06:00 每半小时 ⇒ cron `0,30 23,0-6 * * *`、maxRuns 15）。
