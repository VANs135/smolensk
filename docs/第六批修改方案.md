**P0 → S → R → M → A → F → U → T**。

- **P0** 是三条最便宜的真 bug/缺口（跨段轰炸账本、轮式停车突袭、射程未判），先修可立刻改善可玩性，且互不依赖。
- **S（初设）→ R（增援）→ M（移动）→ A（空军）→ F（战斗）** 是用户使用频率最高的主链；S 的分方游标与"确认"是 R/M 单会话骨架的样板。
- **F** 与第五批批 E 合并，避免同一批文件两轮返工。
- **U** 横切（UI 最简化、SP 投影、迷雾裁剪）放后，避免与前面批次的面板重排互相冲突；**T**（20.0 触点）独立，最后做。
