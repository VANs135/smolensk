## 2. 追溯顺序（约定）

1. 号形如 `1.x`–`5.x` ⇒ **先查专规**；查不到再查通规。
2. 号形如 `6.0`–`21.x` ⇒ **查通规**（专规不覆盖这一段）。
3. 15.1A/15.2A 一类「字母后缀」是**派生编号**：原文把子项写成独立的 `A)`/`B)` 行（不带号前缀），本仓库记作 `15.1A`；追溯按「15.1 的 A) 项」查（见 `条款号可追溯性核对-2026-11-22.md`）。

## 3. 已知做法与代价

- 代码里裸写专规号（如 `'5.0a'`、`'2.3e'`）是历史沿用，`rule` 值同时也进日志与 trace。若要彻底隔离（如加 `sop:` 前缀），会改动全部失败码与既有测试断言，收益不抵风险，**暂不做**。
