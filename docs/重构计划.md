# OCS 斯摩棱斯克重构计划

更新：2026-11-05，按用户要求调整优先级后，已按本计划恢复程序重构。后续开发以本文件的执行顺序为准，历史批次文档中的“下一步”不再决定当前排期。

## 目标与范围

首要目标是：玩家从选择剧本、新建对局开始，通过正式界面完成合法初设，再按规则执行双方完整游戏回合、每回合增援及苏德专规，并正确使用各单位在相应环节中的合法行动。保留现有地图、单位数据、Vue/Pinia/Canvas技术栈及存档兼容，继续渐进修复和解耦。

剧本初设、德军初设抽取放置、逐回合增援和苏军慢动员等已由用户报告存在问题，列为P0前置关卡。当前先登记为待复现和待验收，不因已有函数或历史测试通过而宣称这些流程正确；也不能仅加载预制盘面绕开初设后签收完整流程。

一个完整游戏回合（Game Turn）包括：回合准备 → 先手方A–H → 后手方A–H → 回合结束；未达到终局则进入下一回合准备，达到终局则按规则收束。每方的E反应阶段由对方执行允许的行动，不能把“阶段玩家”直接等同于“当前操作者”；先手也不能固定假设为轴心国。

“各单位各行动”指本作规则、剧本及已启用选项允许的行动。设施、SP及标记按自身能力验收，不强行赋予地面移动或攻击能力；互斥模式、不同日期、不同战果分支通过多个合法场景覆盖，不要求同一单位在一次回合中做完互斥动作。

空运、空投、联合承运、分货和部分返航降为低优先级待办，停止作为下一批主线。地面补给、燃料、运输点、铁路和ZOC仍是高优先级，直接推进，不再等待空运完成。常用空军的整备、轰炸、空战、拦截、防空和返航继续纳入完整回合。

## 交付分层与最终完成标准

| 交付               | 必须达到的结果                                                                          | 尚未完成时的表述                                 |
| ------------------ | --------------------------------------------------------------------------------------- | ------------------------------------------------ |
| R0：合法开局与日程 | 各可选剧本能从新建完成初设、抽签处置及必选落位，正确进入首回合；增援和专规日程核对完整  | 初设、抽取落位或开局交接有阻断，即未通过前置关卡 |

## 剧本初设、逐回合增援与苏德专规

### S1：从选剧本到真实开局

为每个可选剧本建立初设对照表：规则原文/勘误、初设来源及继承关系、起止日期、先摆方与先手方、首回合天气、单位与军力、模式与状态、SP与卡车载货、基地/工事/铁路、死亡堆/容器、专规与已启用选项。不能把共用初设等同于共用全部日程或规则。

| 检查项           | 必须核对的行为                                                                                    | 验收证据                                                                                      |
| ---------------- | ------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| 剧本与变体       | 默认规则、剧本覆盖及选择的选项各自生效；晚起始剧本正确带入已发生的历史状态                        | 所有可选剧本逐项对照；不能只验收入门剧本                                                      |
| 双方布设与自由项 | 固定格、范围内、同HQ、合法基地等约束，摆放顺序、数量、军力、正反面及限制状态正确                  | 自动项和玩家选择均通过正式初设界面完成，非法落点拒绝                                          |
| 初设资源与地图   | 卡车满/空载、SP数量及启用时的装甲集群归属；飞机激活与减损分别记录；铁路、设施、标记及控制状态正确 | 逐项盘面对账，不能重复计入载货或把减损当非激活                                                |
| 德军编队抽取     | 按当前剧本/变体确定抽取池、数量、分组及组间排斥；结果有固定种子和记录                             | 同种子可复核，不重复抽同一不允许重叠的编队；返回界面、重试、读档不重抽                        |
| 抽中后的处置     | 按剧本处理西移、编成变化、死亡堆交换或其它组别结果；核对师及适用所属部件、编内卡车和附属单位      | 每一抽签组、每一编队都有处置清单；原单位和替换单位只在合法位置出现一次                        |
| 德军必选放置     | 需要玩家选择的团/营或落点明确停下；沿道路西移等限制核对路径、方向与距离                           | 不用任意手填坐标或备注代替规则；必选项未完不能确认初设或开局                                  |
| 确认与开局       | 抽取结果、初设列表、地图、死亡堆/盒内清单一致；双方确认后按剧本进入首个合法环节                   | 开局失败可返回修正，重复确认/开始不复制单位或资源；初设抽取不在每回合增援重做                 |
| 重置与保存       | 换剧本、继承剧本、重新开始及初设恢复保持状态对应                                                  | 旧抽签池、落位、选项和确认状态不串局；若支持初设保存，须恢复抽签和已摆/未摆进度，否则明确拒绝 |

S1必须从新建对局验收。预制合法局面只用于补充单项复现，不能替代德军抽取、玩家放置、双方确认和真实开局。

已有的初设西移“视为有道路”用户裁定保留，核对其适用剧本及格/路径范围（历史依据见[第六批修改方案](第六批修改方案.md)），不能扩展为全图道路规则。还须区分“必须放置”“规则允许玩家主动不放置”和“仍待选择”；未完成必做项不能自动变成移除、保留原格或已完成。

### S2：每回合增援和日程账本

对每个剧本、每一方、每个覆盖回合建立完整日程表，关联到达卡、补给/补员表、专规及勘误。条目至少区分：单位到达、SP/补员资源、移除/撤离、转换/替换、解锁/奖励、随机事件及玩家待选事项；明确本回合无事件也应得到的结果。

| 检查项         | 必须覆盖                                                                                                                  |
| -------------- | ------------------------------------------------------------------------------------------------------------------------- |
| 日期与适用范围 | 印刷日期与回合轨映射、剧本起止和继承/变体；晚起始剧本已在初设体现的条目不重发；不能把到达、动员解锁和随机事件混成同一触发 |
| 双方身份与先后 | 只在规定方和时点处理；先手变化不改变所属方；同日到达、转换、解锁等的先后依规则明确                                        |
| 单位与资源解析 | 每个师/团/营、编队部件、数量、减损、卡车载货及空军状态对应真实记录；名称或ID无法匹配是待修缺口，不能静默跳过并标已完成    |
| 合法到场       | 指定入口、范围、HQ、基地、边缘补给源或适用离图盒等条件；SP铁路城市投放、轨距/连通/限额、补给源关闭及启用的归属限制        |
| 到达后状态     | 单位军力、模式、锁定、可用MP、燃料/载货和行动资格正确；移除与替换不会留下重复实例或孤立编队部件                           |
| 待选与异常     | 必选落点、选择单位、无候选、候选不足、迟到/延后、库存不足分别按规则处理；不能无提示漏发，也不能用补填数字完成             |
| 一次性提交     | 掷表与结果处置分开登记；重复点击、切回同环节、双入口调用及保存恢复不再掷骰、不再发放、不再扣除或移除                      |
| 连续跨回合     | 正常回合以及每个关键日期的前一回合→触发回合→后一回合；比较预期、待处理、已处理、选择与剩余量，跨回合状态不丢失            |

日程、触发、抽取、玩家选择、盘面提交及已处理记录分别明确所有权，并一起覆盖保存恢复。强制事项未完不能提前清账或进入下一个环节；可选事项的放弃也要有明确规则和记录。

### 苏军慢动员及其它苏军专规

慢动员单独设专项，不以普通预备释放或单个算子的手工解锁替代：

1. 按30、28、24集团军及真实所属师建立待动员名单，区分师、师的多个算子和可自由行动的独立单位；到达时是否锁定、晚起始剧本应已解锁多少均按规则核对。
2. 按动员表核对日期、集团军、当次新增额度、已用额度和剩余锁定师；由苏方选择允许的具体师。不能把全图锁定算子总数当师数，也不能解锁到另一集团军或任取列表前几枚。
3. 选中师的相关部件按规定一致改变状态；移动、拆分及其它受影响行动逐项按专规核对，不把动员锁误当DG或普通预备，也不擅自扩大禁止范围。
4. 覆盖错方、错日、跨集团军、超额、重复选择、师已解锁、未到场/已移除和候选不足。能否保留未用额度、处理时点及先后必须有原文依据；重试、读档、换环节不能重新获得配额。
5. 连续验证“增援到场→带锁状态→动员选择→解锁后的合法行动→下一回合状态”；不能只检查显示标记改变。

其它苏军专规至少逐项列入：首回合移动限制及剧本变体、补给源关闭及增援落点、警报单位、方面军预备队的资源/转换/免费重建、特殊补员、战略模式/工事等作战限制解除日期、炮兵合并、NKVD战斗要求、苏机限制及相关例外。按当前剧本和规则开关核对触发、玩家选择、费用/数量与实际盘面效果；方面军预备队仍有转换、重建或放置待办时不能只发SP便视为完成。

### 德军专规与初设后的衔接

除S1德军初设抽取外，独立核对：初设满载和SP归属、后续补给的分配/归属、装甲集群分界与后勤限制、治安与运输破坏、建造标记、随机事件/补给列车、可变撤离、到达卡移除/转换和适用的铁路修理限制。只对该剧本和已启用的条款执行；初设一次事项不能变成每回合事项，按回合或日期触发的事项也不能只在初设执行一次。

每条苏德专规登记规则来源、条款、剧本、默认/可选状态、触发日期与时点、操作者、候选/选择、状态及失效时点、界面入口和验收证据。通用规则与本作同号条款须区分来源，避免混用，例如通用规则与斯摩棱斯克专规的“2.4”。启用、关闭及变体分支均要按当前对局实际选择验证。

专规不是只检查是否弹出提示：还要检查后续移动、补给、战斗、段末义务和保存恢复确实读到结果。

## 一回合逐环节验收

本表从S1完成的真实开局继续；回合前初设、抽签及放置另以R0验收，不能省略。每次进入B增援及其它专规时点，还必须执行S2的当期条目和待选事项。

| 阶段/环节               | 必须真实执行的内容                                                              | 放行到下一环节前核对                                                                 |
| ----------------------- | ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |

## 高频共用规则的处理要求

### ZOC

分别核对投射、移动进入/离开、突袭、战斗资格、撤退、战后推进、铁路、抽取/投递/追溯、整备等操作的效果，区分可抵消和不可抵消。不能把普通移动的ZOC政策复制到补给或撤退。

凡规则允许抵消且正式行动依赖该抵消，计划需明确承担单位、路径/用途与承诺时点；成功提交才写入本阶段MP约束，失败预览不锁兵。覆盖先使用后尝试移动、先移动后使用、多条路径共享承担者、承担者离开或损失，以及存读档和阶段切换。

### 补给、燃料与资源

追溯补给、图上SP消耗、部队储备、燃料分开记账；HQ/延补/铁路来源同源规则与本作限制分别验证。常用地面SP搬运及防接力在A3执行，空运专用搬运与离图货源在B后补。任何库存变化都需有来源和去向，不能靠输入数字生出资源。

### 炮击、战斗与移动交接

按9.2核对宣布、补给、行动值、地形/攻防比、奇袭与战果、损失/选项、撤退及推进等顺序；具体次序以规则核对结果为准。目标方决策、不可承担损失、无合法撤退路径、全灭、夺取设施、突袭前后MP都要有处理。已付款或已掷骰的状态不能因关闭、改选、撤销或重试而重结。

### 阶段与保存

只有真实生命周期边界才能清额度或标记；同阶段切环节、重选当前阶段不能清账。检查回合/阵营编辑入口与正式推进，明确演练工具和正式对局的权限，不能用编辑工具补流程。

首先保证合法结算点保存恢复完整，恢复后下一行动、位置、库存、额度、操作者和骰序一致；未完结算须明确拒绝保存或完整持久化。通用的战斗/任务任意中途保存作为低频增强，不能阻塞R1/R2。

## 综合验收办法

1. 每个可选剧本分别从新建对局完成S1初设至首个合法行动，含初设继承、德军抽取与适用变体。先以维捷布斯建立短流程，再验收有编队抽取及更复杂初设的剧本；预制合法局面只补充单项复现，不能替代开局证据。
2. 从真实开局编排有实际行动的双方完整回合：整备/增援及当期专规 → 移动与加油 → 补给与损耗 → 对方反应 → 炮击和战斗 → 撤退/推进 → 进击 → 清理与交接。记录种子、日期、双方资源及全部单位；正式执行过程中禁止手改坐标、补SP、切阶段绕过待办，不能全程空过后宣布可玩。
3. 各剧本逐回合核对S2日程，以连续的前一回合→触发回合→后一回合和晚起始剧本覆盖关键日期；将增援、苏军动员选择及解锁后的移动/补给/战斗连起来。补充合法场景覆盖天气、先手顺序、互斥动作及其它专规分支，B待办保持可见。
4. 自动流程逐步核对盘面、资源、MP/状态、待办、死亡堆、骰序和下一合法行动；人工在正式界面复做同样的决策，检查按钮、选兵、点图、提示和不能继续的原因。
5. 在合法保存点保存/读取后接着做下一行动，再完成剩余回合；验证普通成功、非法拒绝、资源不足、重复点击、中止/放弃、战斗极端结果。
6. 出具逐剧本初设表、逐回合增援/专规日程表及逐单位行动结果表；R0/R1/R2签收列清未验项与B待办，最终R3不得有适用行动缺项、P0/P1阻断或靠备注代替的结算。
