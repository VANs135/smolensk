# OCS 斯摩棱斯克重构计划

更新：2026-11-02。此文件为后续批次的执行清单；历次重构文档记录各轮实际改动。本计划不把现有测试通过等同于规则全覆盖，也不预设交付日期。

## 目标与决策

继续渐进重构，保留地图、算子数据、现有规则函数、Vue/Pinia/Canvas 技术栈及存档兼容。优先修正能让对局卡死、资源凭空增加、结算被跳过或重复执行的问题，再迁移相关状态。每批形成可运行、可审查、已推送的提交，避免长期维护一套不可玩的平行实现。

完成标准：从真实剧本开局，双方按 SOP 完成行动、反应与结算，直到剧本终局；需要玩家决定时明确停下，不能靠手改数据、跳阶段或备注替代规则执行。

模块边界与性能优化依据见[解耦与优化方案](解耦与优化方案.md)。先迁移规则、流程与提交所有权；查询缓存、重绘和拆包按测量结果安排，保留现有技术栈。

## 当前基线

已拆出阶段协调、快照注册、交战现场、掷骰与结果提交、补给阶段、地面移动运行状态及空军任务运行状态。地面移动和空军任务分开；ZOC 已按具体动作区分；部分不可逆操作增加撤销保护。

这些是基础改造，不能视为全域验收。`workbench.ts` 仍接近两万行，部分规则事实构建、跨域提交和资源账本仍集中在其中。任务与轰炸归属、地图基地SP账本已接入；本轮1B.0补上单位运输当量、真实起点和防空单位货损。补给路径ZOC抵消承诺、SP防接力搬运、逐机载货与返航分配仍是未完成项。

## 各域设计约束

### 行动与提交

预览只读；正式操作先校验，再确定骰序和变更计划，最后统一落盘。提交失败不应留下半笔扣款、半次减损或已消耗的出动次数。重试继续已确认的状态，不能通过取消或改选重掷。暂时没有事务能力的入口应先覆盖故障用例，再迁移。

### 资源与所有权

SP 统一按 T 计算，界面再显示 SP/T；库存、载货、落地、退回及损失必须能对账。地面单位、飞机、空军任务、炮击和战斗之间传递明确的归属，不能仅凭“同一目标格存在一个结果”推断本次已完成。反应段和目标方决策不能沿用阶段玩家身份。

### 规则、ZOC 与移动

OCS 4.3 加本作专规与勘误为依据，明确记录用户已确认的规则口径。地面逐格 MP、空军任务航程、补给抽取/投送路径、撤退和战后推进分别建模。ZOC 投射与抵消效果分开；可抵消的操作还必须履行 4.5b 承诺。规则含糊处保留来源和判定理由，不默默发明新规则。

### 存档与兼容

继续兼容旧档，不以一次性清空数据解决迁移。新增持久状态必须同步快照字段、默认值、迁移、恢复顺序与回归用例。当前仍以完整结算点保存为基础；支持战斗或空军任务中途恢复前，必须把所有待决状态和随机进度一并设计，不能只保存盘面。

1. 记录真实触发条件、错误结果、对应规则与影响范围。
2. 增加能复现问题的行为用例；规则矩阵使用引擎测试，跨域操作使用真实 store/SOP 入口。源码文本守卫只作辅助。

每批报告写明实际完成、测试证据和剩余缺口。没有用真实入口验证的流程标为待验收，不使用“整体已完成”的结论。

守恒检查统一为：任务装载量 = 仍在途 + 已送达 + 已损失 + 已退回；地面库存减少量与装载量一致。每件1T只有一种最终去向。部分返航和减损不能仅改变总容量而不改变货物归属。

1B执行时先完成**1B.0载货事实与货损**：原程序把单位按0T计，使用战斗面MA，且防空货损只移出清单、不淘汰单位。这些会使后续逐机分配建立在错误载荷上，因此本轮先修复，记录见[单位载货与防空货损](2026-11-02-单位载货与防空货损.md)。

**1B.1仍待实施**，下一批依次做：

1. 为逐机/同基地合并载荷设计明确货单，保留半T合运和14.4g玩家选择货损的权利。
2. 处理主动返航、空战/拦截中止、飞机摧毁后的去向和运力；无存活承运机时不得继续投送。
3. 为分机货单提供实际选择和预览，失败不扣款、不中途丢货；再解除SP途中改编或部分返航限制。
4. 共同卸载量与完整货物选择本轮已接入；超限义务已绑定收据，当前支持全部运输机留场。接下来让拒卸SP随实际承运飞机返航，并支持按逐机货单处理部分留场。
5. 覆盖“同基地两架半T合运”“多基地各自装载”“一架中止/全灭”“部分返航”“转返另一基地”“重试及失败后下一合法操作”，才能验收1B。

1B.0不是逐机运输完成：单位装载时的来源及基地容量已校验，但地面货物在途状态、分机归属、分机返航尚未建立。

本批同时补齐单位载货的保存保护：SP及单位载货任务未结束时均拒绝保存，返航结束后允许保存；不把半笔任务写成完整盘面。

1A 的支持边界是**共同地图起飞基地的SP编队**：自动按该格己方地面库存装载，不从异地、敌方、地面运输算子或离图虚拟格取货。多基地SP装载会明确拒绝。载有SP时，暂不支持任务中途加机或拆分载货返航；拒卸SP当前按原基地退运。以上是实现边界，不是新增规则。1B 必须解除这些限制并核对实际货物流向后，才能验收完整运输循环。

载货任务当前不支持中途存档；任务结束后仍采用 v6 盘面格式。1B/1C 若要支持中途恢复，须先让货单、逐机归属、待决货损、骰序和阶段义务一起持久化，不能仅保存已扣减的地面库存。
